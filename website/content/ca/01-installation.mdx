## Requisits [#requirements]

- Un entorn d'execució que pugui gestionar mòduls ES, com Node.js
- Cal `valibot@^1.0.0` com a dependència d'iguals

`message` segueix `lang` de `getGlobalConfig()` de Valibot.

## Instal·lació [#installation]

```package-install
npm i i18n-error-base
```

Si Valibot encara no està instal·lat, afegiu-lo també.

```package-install
npm i valibot
```

:::warning[Atenció a la dependència d'iguals]
`valibot` no s'inclou. Sense `valibot@^1.0.0`, la importació no es pot resoldre.
:::

## Importació [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```
