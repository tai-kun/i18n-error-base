És una classe base per heretar `Error` que canvia `message` dinàmicament segons la configuració global d'idioma (`lang`) de Valibot.

```ts
import { setGlobalConfig } from "valibot";
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";

class NotFoundError extends I18nErrorBase<{ resource: string }> {}

setErrorMessage(NotFoundError, ({ resource }) => `リソースが見つかりません: ${resource}`, "ja");
setErrorMessage(NotFoundError, ({ resource }) => `Resource not found: ${resource}`, "en");

const error = new NotFoundError({ resource: "user" }, "fallback message");

setGlobalConfig({ lang: "ja" });
console.log(error.message); // リソースが見つかりません: user

setGlobalConfig({ lang: "en" });
console.log(error.message); // Resource not found: user
```

Com que `lang` es consulta cada vegada que s'accedeix a `message`, es pot canviar d'idioma sense tornar a crear les instàncies. Per als idiomes sense registre, es recorre al missatge per defecte passat al constructor.

## Característiques [#features]

- Resol `message` dinàmicament enllaçant amb `getGlobalConfig()` / `setGlobalConfig({ lang })` de Valibot
- Els missatges per idioma es registren posteriorment amb `setErrorMessage`. També s'hi poden registrar funcions que reben `meta`
- Per als idiomes sense registre, es recorre al missatge per defecte del constructor
- Es pot afegir un prefix al començament del missatge amb `static prefix` per classe
- Conserva `meta` al constructor i la passa a les funcions de generació de missatges
- Com que hereta `Error`, `instanceof Error`, `cause` i `stack` es poden utilitzar tal qual
- Com que els missatges es desen en un `WeakMap`, les classes que ja no calen es recullen com a brossa

## Com funciona [#how-it-works]

El constructor de `I18nErrorBase` defineix `message` com a getter. Es resol en l'ordre següent a cada accés.

1. Obté `lang` de `getGlobalConfig()`. Si no està configurat, és `"en"`
2. Si hi ha una funció `(classe × lang)` registrada amb `setErrorMessage`, l'executa passant-hi `meta`
3. En cas contrari, retorna el missatge per defecte passat al constructor (una cadena o el resultat d'una funció)
4. Si `static prefix` està configurat, el concatena al principi

:::tip
La forma funcional del missatge per defecte s'avalua en el primer accés i després es desa a la memòria cau. Els missatges dels idiomes registrats es regeneren des de `meta` a cada accés, de manera que el canvi d'idioma es reflecteix immediatament.
:::
