Clasă de bază pentru extinderea `Error`, care comută dinamic `message` în sincron cu setarea globală de limbă (`lang`) a Valibot.

```ts
import { setGlobalConfig } from "valibot";
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";

class NotFoundError extends I18nErrorBase<{ resource: string }> {}

setErrorMessage(NotFoundError, ({ resource }) => `リソースが見つかりません: ${resource}`, "ja");
setErrorMessage(NotFoundError, ({ resource }) => `Resource not found: ${resource}`, "en");

const error = new NotFoundError({ resource: "user" }, "fallback message");

setGlobalConfig({ lang: "ja" });
console.log(error.message); // リソースが見つかりません: user

setGlobalConfig({ lang: "en" });
console.log(error.message); // Resource not found: user
```

Deoarece `lang` curent este consultat la fiecare accesare a `message`, puteți schimba limba fără a recrea instanțele. Pentru limbile fără mesaj înregistrat, se revine la mesajul implicit transmis constructorului.

## Caracteristici [#features]

- Rezolvă dinamic `message` în sincron cu `getGlobalConfig()` / `setGlobalConfig({ lang })` din Valibot
- Mesajele pe limbi se înregistrează ulterior cu `setErrorMessage`. Se pot înregistra și funcții care primesc `meta`
- Pentru limbile fără înregistrare, se revine la mesajul implicit din constructor
- Adaugă un prefix la începutul mesajului prin `static prefix` la nivel de clasă
- Păstrează `meta` în constructor și îl transmite funcțiilor de generare a mesajelor
- Deoarece moștenește `Error`, `instanceof Error`, `cause` și `stack` funcționează ca de obicei
- Mesajele sunt stocate într-un `WeakMap`, astfel clasele neutilizate pot fi eliberate de garbage collector

## Cum funcționează [#how-it-works]

Constructorul `I18nErrorBase` definește `message` ca getter. La fiecare accesare este rezolvat în următoarea ordine.

1. Obține `lang` din `getGlobalConfig()`. Când nu este setat, este `"en"`
2. Dacă există o funcție `(clasă × lang)` înregistrată cu `setErrorMessage`, o execută cu `meta`
3. În caz contrar, returnează mesajul implicit transmis constructorului (un șir sau rezultatul unei funcții)
4. Dacă `static prefix` este setat, îl adaugă la început

:::tip
Forma funcțională a mesajului implicit este evaluată la primul acces și apoi memorată în cache. Mesajele pentru limbile înregistrate sunt regenerate din `meta` la fiecare accesare, astfel comutarea limbii se reflectă imediat.
:::
