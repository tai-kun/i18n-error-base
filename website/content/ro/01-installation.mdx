## Cerințe [#requirements]

- Un mediu de execuție care poate gestiona module ES, cum ar fi Node.js
- `valibot@^1.0.0` este necesar ca dependență peer

`message` urmează `lang` din `getGlobalConfig()` al Valibot.

## Instalare [#installation]

```package-install
npm i i18n-error-base
```

Dacă Valibot nu este încă instalat, adăugați-l de asemenea.

```package-install
npm i valibot
```

:::warning[Atenție la dependența peer]
`valibot` nu este inclus. Fără `valibot@^1.0.0`, importul nu se rezolvă.
:::

## Import [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```
