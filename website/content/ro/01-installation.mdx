## Cerințe [#requirements]

- Un mediu de execuție care poate gestiona module ES, cum ar fi Node.js
- `valibot@^1.0.0` este necesar ca dependență peer

`I18nErrorBase` consultă intern `getGlobalConfig()` din Valibot pentru a obține `lang` curent. Chiar și în proiectele care nu folosesc Valibot, este suficient să apelați `setGlobalConfig({ lang })` doar pentru comutarea limbii.

## Instalare [#installation]

```package-install
npm i i18n-error-base
```

Dacă Valibot nu este încă instalat, adăugați-l de asemenea.

```package-install
npm i valibot
```

:::warning[Atenție la dependența peer]
`i18n-error-base` nu include `valibot`. Dacă proiectul gazdă nu furnizează `valibot@^1.0.0`, importul va eșua la rezolvare.
:::

## Import [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```

Este disponibil și un export implicit.

```ts
import I18nErrorBase from "i18n-error-base";
import setErrorMessage from "i18n-error-base";
```

:::note
Pachetul este distribuit ca ESM (`"type": "module"`) fără efecte secundare (`"sideEffects": false`). Definițiile de tipuri sunt rezolvate din `dist/src/*.d.ts`.
:::
