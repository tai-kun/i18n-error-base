## Fluxul de bază [#basic-flow]

<Steps>
  <Step title="Definiți o clasă de eroare">
    Extindeți `I18nErrorBase<TMeta>` și definiți ca `TMeta` informațiile pe care doriți să le folosiți pentru generarea mesajelor.
  </Step>
  <Step title="Înregistrați mesajele pe limbi">
    Înregistrați mesajul corespunzător clasei și limbii cu `setErrorMessage`.
  </Step>
  <Step title="Comutați limba și citiți message">
    Comutați cu `setGlobalConfig({ lang })` din Valibot și accesați `error.message`.
  </Step>
</Steps>

```ts
import { setGlobalConfig } from "valibot";
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";

class BusinessRuleError extends I18nErrorBase<{ code: string; limit: number }> {
  public constructor(meta: { code: string; limit: number }) {
    super(meta, ({ code, limit }) => `Code: ${code}, Limit: ${limit}`);
  }
}

setErrorMessage(
  BusinessRuleError,
  ({ code, limit }) => `コード: ${code}、制限: ${limit}`,
  "ja",
);

const error = new BusinessRuleError({ code: "ERR", limit: 50 });

setGlobalConfig({ lang: "ja" });
console.log(error.message); // コード: ERR、制限: 50

setGlobalConfig({ lang: "en" });
console.log(error.message); // Code: ERR, Limit: 50
```

## Definirea unei clase de eroare [#define-error-class]

`TMeta` este tipul informațiilor auxiliare folosite pentru generarea mesajelor. Este păstrat ca `error.meta` și transmis, de asemenea, funcției date lui `setErrorMessage`.

```ts
import { I18nErrorBase } from "i18n-error-base";

class NotFoundError extends I18nErrorBase<{ resource: string }> {}

const error = new NotFoundError({ resource: "user" }, "fallback message");
console.log(error.meta); // { resource: "user" }
```

Al doilea argument al constructorului este un șir sau o funcție `(meta) => string`. Al treilea argument acceptă aceleași opțiuni ca `Error`, cum ar fi `{ cause }`.

```ts
class TestError extends I18nErrorBase<{ code: string }> {}

const cause = new Error("original");
const error = new TestError({ code: "ERR" }, "something went wrong", { cause });
console.log(error.cause === cause); // true
```

Setarea `TMeta` la `undefined` vă permite să omiteți `meta`.

```ts
class NoMetaError extends I18nErrorBase<undefined> {}

const a = new NoMetaError("no meta");
const b = new NoMetaError(undefined, "no meta");
console.log(a.meta); // undefined
```

:::note
`I18nErrorBase` nu este destinat să fie construit direct cu `new`. Creați și utilizați întotdeauna o subclasă concretă. Înregistrările mesajelor sunt distinse per constructor (`this.constructor`), astfel un mesaj înregistrat pe o clasă părinte nu este niciodată moștenit de o clasă copil.
:::

## Înregistrarea mesajelor [#register-message]

`setErrorMessage` înregistrează o funcție de creare a mesajelor pentru o clasă și o limbă.

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";

class TestError extends I18nErrorBase<{ code: string }> {}

setErrorMessage(TestError, ({ code }) => `エラーコード: ${code}`, "ja");
setErrorMessage(TestError, "something went wrong", "en");
```

Un șir este convertit intern în `() => text`. Limbile pot fi specificate și ca un tablou de șiruri.

```ts
const message = ({ code }: { code: string }) => `エラーコード: ${code}`;
setErrorMessage(TestError, message, ["ja", "ko", "zh"]);
```

Reînregistrarea aceleiași clase și limbi suprascrie intrarea anterioară. Înregistrarea este utilizată numai atunci când constructorul de la momentul înregistrării și cel de la momentul consultării sunt identice, indiferent de verificările `instanceof`.

:::warning[Atenție la accesarea înainte de înregistrare]
Forma funcțională a mesajului implicit este evaluată și memorată în cache la primul acces. Dacă citiți `message` într-o limbă neînregistrată înainte de a apela `setErrorMessage`, acea valoare implicită devine fixă. Ca regulă, înregistrați mesajele pe limbi înainte de a crea instanțe.
:::

## Comutarea limbilor [#switch-language]

Comutați limbile cu configurația globală a Valibot. `message` consultă `lang` curent la fiecare accesare.

```ts
import { setGlobalConfig } from "valibot";

setGlobalConfig({ lang: "ja" });
console.log(error.message); // 日本語の登録メッセージ

setGlobalConfig({ lang: "en" });
console.log(error.message); // 英語の登録メッセージ or 既定メッセージ
```

Valoarea implicită când `lang` nu este setat este `"en"`. Dacă o limbă solicitată nu are înregistrare, se revine la mesajul implicit transmis constructorului.

```ts
setErrorMessage(BusinessRuleError, () => "日本語メッセージ", "ja");

setGlobalConfig({ lang: "fr" });
console.log(error.message); // "Code: ERR, Limit: 50"（既定メッセージ）
```

## Adăugarea unui prefix [#prefix]

Setarea `static prefix` pe o clasă îl adaugă la începutul mesajului rezolvat. Se aplică atât mesajelor traduse, cât și celor implicite.

```ts
class PrefixedError extends I18nErrorBase<{ code: string }> {
  static {
    this.prefix = "[ERROR] ";
  }
}

setErrorMessage(PrefixedError, ({ code }) => `code is ${code}`, "ja");
const error = new PrefixedError({ code: "ERR" }, "fallback");

setGlobalConfig({ lang: "ja" });
console.log(error.message); // "[ERROR] code is ERR"

setGlobalConfig({ lang: "en" });
console.log(error.message); // "[ERROR] fallback"
```

Când nu este setat, mesajul este returnat ca atare, fără prefix.

## Comportamentul ca Error [#error-behavior]

- `error instanceof Error`, `instanceof I18nErrorBase` și `instanceof <clasa concretă>` sunt toate `true`
- `message` este enumerabil (inclus în `Object.keys(error)`)
- `String(error)` / `error.toString()` includ mesajul rezolvat (de ex. `"Error: ..."`)
- `cause` este păstrat prin `new TestError(meta, message, { cause })`. Ca polyfill pentru mediile de execuție mai vechi, există o tratare care atribuie `options.cause` atunci când `cause` nu este acceptat

## Modele comune [#common-patterns]

### Fixarea mesajului implicit în constructor [#fix-default-message-in-constructor]

```ts
class BusinessRuleError extends I18nErrorBase<{ code: string; limit: number }> {
  public constructor(meta: { code: string; limit: number }, options?: ErrorOptions) {
    super(meta, ({ code, limit }) => `Code: ${code}, Limit: ${limit}`, options);
  }
}
```

Apelanții trebuie să se preocupe doar de `meta`, ceea ce evită duplicarea textului implicit (aici în engleză).

### Înregistrarea mai multor limbi deodată [#register-multiple-languages]

```ts
setErrorMessage(MyError, "エラーが発生しました", ["ja"]);
setErrorMessage(MyError, "An error occurred", ["en", "en-US"]);
```

Codurile de limbă nu sunt normalizate. `"en"` și `"en-US"` sunt tratate ca chei separate, deci înregistrați explicit fiecare cod de care aveți nevoie.
