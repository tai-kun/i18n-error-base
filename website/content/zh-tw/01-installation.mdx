## 執行需求 [#requirements]

- 可處理 ES 模組的執行環境，例如 Node.js
- 需要 `valibot@^1.0.0` 作為對等依賴

`message` 遵循 Valibot `getGlobalConfig()` 的 `lang`。

## 安裝 [#installation]

```package-install
npm i i18n-error-base
```

若尚未引入 Valibot，請一併加入。

```package-install
npm i valibot
```

:::warning[注意對等依賴]
`valibot` 不會綑綁。缺少 `valibot@^1.0.0` 時匯入將解析失敗。
:::

## 匯入 [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```
