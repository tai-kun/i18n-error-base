A base class for extending `Error` that dynamically switches `message` in sync with Valibot's global locale setting (`lang`).

```ts
import { setGlobalConfig } from "valibot";
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";

class NotFoundError extends I18nErrorBase<{ resource: string }> {}

setErrorMessage(NotFoundError, ({ resource }) => `リソースが見つかりません: ${resource}`, "ja");
setErrorMessage(NotFoundError, ({ resource }) => `Resource not found: ${resource}`, "en");

const error = new NotFoundError({ resource: "user" }, "fallback message");

setGlobalConfig({ lang: "ja" });
console.log(error.message); // リソースが見つかりません: user

setGlobalConfig({ lang: "en" });
console.log(error.message); // Resource not found: user
```

Because the current `lang` is resolved each time `message` is accessed, you can switch languages without recreating instances. For languages with no registered message, it falls back to the default message passed to the constructor.

## Features [#features]

- Resolves `message` dynamically in sync with Valibot's `getGlobalConfig()` / `setGlobalConfig({ lang })`
- Register per-language messages later with `setErrorMessage`. You can also register functions that receive `meta`
- Falls back to the constructor's default message for languages with no registration
- Adds a prefix to the beginning of the message via a per-class `static prefix`
- Keeps `meta` in the constructor and passes it to message factory functions
- Inherits from `Error`, so `instanceof Error`, `cause`, and `stack` work as usual
- Stores messages in a `WeakMap`, so unreferenced classes can be garbage collected

## How it works [#how-it-works]

The `I18nErrorBase` constructor defines `message` as a getter. It is resolved in the following order on each access.

1. Get `lang` from `getGlobalConfig()`. It is `"en"` when unset
2. If a `(class × lang)` function registered with `setErrorMessage` exists, run it with `meta`
3. Otherwise, return the default message passed to the constructor (a string or the result of a function)
4. If `static prefix` is set, prepend it to the beginning

:::tip
The function form of the default message is evaluated on first access and cached thereafter. Messages for registered languages are regenerated from `meta` on each access, so language switches take effect immediately.
:::
