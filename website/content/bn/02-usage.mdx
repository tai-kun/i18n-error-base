## মৌলিক প্রবাহ [#basic-flow]

<Steps>
  <Step title="এরর ক্লাস সংজ্ঞায়িত করুন">
    `I18nErrorBase<TMeta>` থেকে উত্তরাধিকার নিন, বার্তা তৈরিতে ব্যবহার করতে চান এমন তথ্য `TMeta` হিসেবে সংজ্ঞায়িত করুন।
  </Step>
  <Step title="প্রতিটি ভাষার বার্তা নিবন্ধন করুন">
    `setErrorMessage` দিয়ে ক্লাস ও ভাষা অনুযায়ী বার্তা নিবন্ধন করুন।
  </Step>
  <Step title="ভাষা বদলে message পড়ুন">
    Valibot-এর `setGlobalConfig({ lang })` দিয়ে বদলে, `error.message` অ্যাক্সেস করুন।
  </Step>
</Steps>

```ts
import { setGlobalConfig } from "valibot";
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";

class BusinessRuleError extends I18nErrorBase<{ code: string; limit: number }> {
  public constructor(meta: { code: string; limit: number }) {
    super(meta, ({ code, limit }) => `Code: ${code}, Limit: ${limit}`);
  }
}

setErrorMessage(
  BusinessRuleError,
  ({ code, limit }) => `コード: ${code}、制限: ${limit}`,
  "ja",
);

const error = new BusinessRuleError({ code: "ERR", limit: 50 });

setGlobalConfig({ lang: "ja" });
console.log(error.message); // コード: ERR、制限: 50

setGlobalConfig({ lang: "en" });
console.log(error.message); // Code: ERR, Limit: 50
```

## এরর ক্লাস সংজ্ঞায়িত করুন [#define-error-class]

`TMeta` হলো বার্তা তৈরিতে ব্যবহৃত আনুষঙ্গিক তথ্যের টাইপ। `error.meta` হিসেবে সংরক্ষিত থাকে, `setErrorMessage`-এর ফাংশনেও পাঠানো হয়।

```ts
import { I18nErrorBase } from "i18n-error-base";

class NotFoundError extends I18nErrorBase<{ resource: string }> {}

const error = new NotFoundError({ resource: "user" }, "fallback message");
console.log(error.meta); // { resource: "user" }
```

কনস্ট্রাক্টরের ২য় আর্গুমেন্ট স্ট্রিং বা `(meta) => string` ফাংশন। ৩য় আর্গুমেন্টে `Error`-এর মতো `{ cause }` ইত্যাদি অপশন দেওয়া যায়।

```ts
class TestError extends I18nErrorBase<{ code: string }> {}

const cause = new Error("original");
const error = new TestError({ code: "ERR" }, "something went wrong", { cause });
console.log(error.cause === cause); // true
```

`TMeta` `undefined` করলে `meta` বাদ দেওয়া যায়।

```ts
class NoMetaError extends I18nErrorBase<undefined> {}

const a = new NoMetaError("no meta");
const b = new NoMetaError(undefined, "no meta");
console.log(a.meta); // undefined
```

:::note
`I18nErrorBase` সরাসরি `new` করা অনুমিত নয়। অবশ্যই উত্তরাধিকারী সুনির্দিষ্ট ক্লাস বানিয়ে ব্যবহার করুন। বার্তার নিবন্ধন-স্থান কনস্ট্রাক্টর-প্রতি (`this.constructor`) আলাদা করা হয় বলে, প্যারেন্ট ক্লাসে নিবন্ধিত বার্তা চাইল্ড ক্লাসে উত্তরাধিকারসূত্রে যায় না।
:::

## বার্তা নিবন্ধন করুন [#register-message]

`setErrorMessage` ক্লাস ও ভাষার জন্য বার্তা তৈরির ফাংশন নিবন্ধন করে।

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";

class TestError extends I18nErrorBase<{ code: string }> {}

setErrorMessage(TestError, ({ code }) => `エラーコード: ${code}`, "ja");
setErrorMessage(TestError, "something went wrong", "en");
```

স্ট্রিং দিলে অভ্যন্তরীণভাবে `() => text`-এ রূপান্তর হয়। ভাষা স্ট্রিংয়ের অ্যারে দিয়েও নির্দিষ্ট করা যায়।

```ts
const message = ({ code }: { code: string }) => `エラーコード: ${code}`;
setErrorMessage(TestError, message, ["ja", "ko", "zh"]);
```

একই ক্লাস ও ভাষায় পুনরায় নিবন্ধন করলে ওভাররাইট হয়। নিবন্ধন-বিষয় `instanceof` নির্ণয়ের সাথে সম্পর্কহীনভাবে, শুধু নিবন্ধন ও রেফারেন্সের সময় কনস্ট্রাক্টর একই হলেই ব্যবহৃত হয়।

:::warning[নিবন্ধনের আগে অ্যাক্সেসে সতর্কতা]
ডিফল্ট বার্তার ফাংশন রূপ প্রথম অ্যাক্সেসে মূল্যায়ন করে ক্যাশ করা হয়। `setErrorMessage`-এর আগে অনিবন্ধিত ভাষায় `message` পড়লে, সেই ডিফল্ট মান স্থির হয়ে যায়। প্রতিটি ভাষার বার্তা নীতিগতভাবে ইনস্ট্যান্স তৈরির আগে নিবন্ধন করুন।
:::

## ভাষা বদলান [#switch-language]

ভাষা Valibot-এর গ্লোবাল সেটিং দিয়ে বদলান। `message` প্রতিটি অ্যাক্সেসে বর্তমান `lang` দেখে।

```ts
import { setGlobalConfig } from "valibot";

setGlobalConfig({ lang: "ja" });
console.log(error.message); // 日本語の登録メッセージ

setGlobalConfig({ lang: "en" });
console.log(error.message); // 英語の登録メッセージ or 既定メッセージ
```

`lang` সেট না থাকলে ডিফল্ট `"en"`। অনিবন্ধিত ভাষা চাইলে, কনস্ট্রাক্টরে দেওয়া ডিফল্ট বার্তায় ফলব্যাক করে।

```ts
setErrorMessage(BusinessRuleError, () => "日本語メッセージ", "ja");

setGlobalConfig({ lang: "fr" });
console.log(error.message); // "Code: ERR, Limit: 50"（既定メッセージ）
```

## উপসর্গ যোগ করুন [#prefix]

ক্লাসে `static prefix` সেট করলে, রিজলভ হওয়া বার্তার শুরুতে যুক্ত হয়। অনুবাদিত বার্তা ও ডিফল্ট বার্তা উভয়ের ক্ষেত্রেই প্রযোজ্য।

```ts
class PrefixedError extends I18nErrorBase<{ code: string }> {
  static {
    this.prefix = "[ERROR] ";
  }
}

setErrorMessage(PrefixedError, ({ code }) => `code is ${code}`, "ja");
const error = new PrefixedError({ code: "ERR" }, "fallback");

setGlobalConfig({ lang: "ja" });
console.log(error.message); // "[ERROR] code is ERR"

setGlobalConfig({ lang: "en" });
console.log(error.message); // "[ERROR] fallback"
```

সেট না করলে উপসর্গ ছাড়াই যথাযথ ফেরত আসে।

## Error হিসেবে আচরণ [#error-behavior]

- `error instanceof Error`, `instanceof I18nErrorBase`, `instanceof` সুনির্দিষ্ট ক্লাস সবই `true`
- `message` এনিউমারেবল (`Object.keys(error)`-তে অন্তর্ভুক্ত)
- `String(error)` / `error.toString()` রিজলভ হওয়া বার্তা অন্তর্ভুক্ত করে (যেমন: `"Error: ..."`)
- `cause` `new TestError(meta, message, { cause })` দিয়ে সংরক্ষিত হয়। পুরোনো রানটাইমের জন্য পলিফিল হিসেবে, `cause` অসমর্থিত হলে `options.cause` বসানোর প্রক্রিয়া আছে

## প্রচলিত প্যাটার্ন [#common-patterns]

### ডিফল্ট বার্তা কনস্ট্রাক্টরে স্থির করুন [#fix-default-message-in-constructor]

```ts
class BusinessRuleError extends I18nErrorBase<{ code: string; limit: number }> {
  public constructor(meta: { code: string; limit: number }, options?: ErrorOptions) {
    super(meta, ({ code, limit }) => `Code: ${code}, Limit: ${limit}`, options);
  }
}
```

ডাক-পক্ষে শুধু `meta` ভাবলেই চলে, ডিফল্ট বাক্যের (এখানে ইংরেজি) পুনরাবৃত্তি এড়ানো যায়।

### একাধিক ভাষা একসাথে নিবন্ধন করুন [#register-multiple-languages]

```ts
setErrorMessage(MyError, "エラーが発生しました", ["ja"]);
setErrorMessage(MyError, "An error occurred", ["en", "en-US"]);
```

ভাষা কোড স্বাভাবিককরণ করা হয় না। `"en"` ও `"en-US"` আলাদা কী হিসেবে গণ্য হয় বলে, প্রয়োজনীয় কোড স্পষ্টভাবে নিবন্ধন করুন।
