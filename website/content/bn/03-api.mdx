## `I18nErrorBase` [#i18n-error-base]

`Error` থেকে উত্তরাধিকারের জন্য বেস ক্লাস। `message`-কে গেটার হিসেবে পুনঃসংজ্ঞায়িত করে, Valibot-এর `lang` অনুযায়ী গতিশীলভাবে রিজলভ করে।

```ts
import { I18nErrorBase } from "i18n-error-base";

class MyError extends I18nErrorBase<{ code: string }> {}
```

### টাইপ প্যারামিটার [#type-params]

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `TMeta` | `ErrorMeta \| undefined` | `ErrorMeta \| undefined` | `meta` হিসেবে সংরক্ষিত আনুষঙ্গিক তথ্যের টাইপ। ব্যবহার না করলে `undefined` নির্দিষ্ট করুন। |

### স্ট্যাটিক প্রপার্টি [#static-props]

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `prefix?` | `string` | `undefined` | সেট করলে রিজলভ হওয়া বার্তার শুরুতে যুক্ত হয়। |

### ইনস্ট্যান্স প্রপার্টি [#instance-props]

| Prop | Type | Description |
| ---- | ---- | ----------- |
| `meta` | `TMeta` | কনস্ট্রাক্টরে দেওয়া আনুষঙ্গিক তথ্য। পড়া-লেখা সম্ভব। |
| `message` | `string` | বর্তমান `lang` অনুযায়ী রিজলভ হওয়া বার্তা। এনিউমারেবল। |
| `cause` | `unknown` | `ErrorOptions` দিয়ে দেওয়া কারণ। `Error`-এর মানক প্রপার্টি। |

### কনস্ট্রাক্টর [#constructor]

`TMeta`-তে `undefined` না থাকলে, `meta` আবশ্যক।

```ts
new MyError(meta, message, options?)
```

`TMeta` `undefined` হলে, `meta` বাদ দেওয়া যায়।

```ts
new MyError(message, options?)
new MyError(meta, message, options?)
```

| প্যারামিটার | ধরন | বর্ণনা |
| ------------ | -- | ---- |
| `meta` | `TMeta` | বার্তা তৈরিতে ব্যবহৃত আনুষঙ্গিক তথ্য। |
| `message` | `string \| MessageFactory<TMeta>` | নিবন্ধন নেই এমন ভাষায় ব্যবহৃত ডিফল্ট বার্তা। ফাংশন হলে `meta` গ্রহণ করে। |
| `options` | `ErrorOptions` | `Error`-এর ২য় আর্গুমেন্টের সাথে সামঞ্জস্যপূর্ণ অপশন (`{ cause }` ইত্যাদি)। |

`message`-এ স্ট্রিং ছাড়া মান (সংখ্যা ইত্যাদি) দিলে `String(...)` দিয়ে স্ট্রিং করা হয়। মেসেজ ফ্যাক্টরি খালি স্ট্রিং ফেরত দিলে `message`-ও খালি স্ট্রিং হয়।

### রিজলিউশন ক্রম [#resolution-order]

1. `getGlobalConfig()`-এর `lang` নেয় (সেট না থাকলে `"en"`)
2. `setErrorMessage` দিয়ে নিবন্ধিত সংশ্লিষ্ট ক্লাস・সংশ্লিষ্ট ভাষার ফাংশন `meta` সহ চালায়
3. অনিবন্ধিত হলে কনস্ট্রাক্টরের ডিফল্ট বার্তা (স্ট্রিং বা ফাংশনের মূল্যায়ন ফলাফল। প্রথম মূল্যায়নের পর ক্যাশ) ব্যবহার করে
4. `static prefix` থাকলে শুরুতে যুক্ত করে

:::note
নিবন্ধনের মিল `this.constructor`-এর পূর্ণ সমতা। প্যারেন্ট ক্লাসে নিবন্ধন চাইল্ড ক্লাসে উত্তরাধিকারসূত্রে যায় না। প্রয়োজনীয় প্রতিটি ক্লাসে নিবন্ধন করুন।
:::

## `setErrorMessage` [#set-error-message]

প্রতিটি ভাষার বার্তা তৈরির ফাংশন নিবন্ধন করে।

```ts
import { setErrorMessage } from "i18n-error-base";

setErrorMessage(MyError, (meta) => `...: ${meta.code}`, "ja");
```

| প্যারামিটার | ধরন | বর্ণনা |
| ------------ | -- | ---- |
| `reference` | `I18nErrorBaseConstructor` | `I18nErrorBase` থেকে উত্তরাধিকারী ক্লাস। উত্তরাধিকারী নয় এমন ক্লাস টাইপ ত্রুটি হয়। |
| `message` | `string \| (meta) => string` | নিবন্ধন করার বার্তা। `meta`-এর টাইপ লক্ষ্য ক্লাসের `meta` থেকে অনুমান করা হয়। |
| `lang` | `string \| Iterable<string>` | লক্ষ্য ভাষা। একক কোড বা কোডের ইটারেবল অবজেক্ট (অ্যারে ইত্যাদি)। |

স্ট্রিং অভ্যন্তরীণভাবে ফাংশনে রূপান্তর করে সংরক্ষণ করা হয়। একই ক্লাস・একই ভাষায় পুনর্নিবন্ধন ওভাররাইট। সংরক্ষণস্থল `globalThis.i18n_error_base__message_map`-এর `WeakMap`, কী ক্লাস, মান ভাষা থেকে ফাংশনে `Map`।

## ধরন [#types]

### `ErrorMeta` [#error-meta]

```ts
type ErrorMeta = {
  readonly [prop: string]: unknown;
};
```

`TMeta`-এর ডিফল্ট সীমাবদ্ধতা। যেকোনো প্রপার্টিযুক্ত রিড-অনলি অবজেক্ট বোঝায়।

### `ErrorOptions` [#error-options]

```ts
type ErrorOptions =
  ConstructorParameters<typeof Error> extends [
    message?: unknown,
    options?: (infer TOptions) | undefined,
  ]
    ? TOptions
    : { readonly cause?: unknown };
```

রানটাইমের `Error` কনস্ট্রাক্টর ২য় আর্গুমেন্ট থেকে উদ্ভূত টাইপ। `cause` সহ অপশন দেওয়া যায়। পরের শাখা পুরোনো পরিবেশের জন্য ফলব্যাক।

### `MessageFactory<TMeta>` [#message-factory]

```ts
interface MessageFactory<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> {
  (meta: TMeta): string;
}
```

`meta` থেকে বার্তা তৈরির ফাংশন। কনস্ট্রাক্টরের ডিফল্ট বার্তা ও `setErrorMessage`-এর নিবন্ধন মান উভয়েই ব্যবহারযোগ্য।

### `I18nErrorBaseParams<TMeta>` [#i18n-error-base-params]

কনস্ট্রাক্টর আর্গুমেন্টের ওভারলোড বোঝানো টাইপ।

```ts
type I18nErrorBaseParams<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> =
  [TMeta] extends [undefined]
    ?
        | [message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
        | [meta: undefined, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
    : [meta: TMeta, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined];
```

`TMeta` `undefined` হলেই শুধু `meta`-বিহীন রূপ অনুমোদিত।

### `I18nErrorBaseConstructor` [#i18n-error-base-constructor]

```ts
interface I18nErrorBaseConstructor {
  new (...args: any): I18nErrorBase;
}
```

`setErrorMessage`-এর ১ম আর্গুমেন্টের টাইপ। অভ্যন্তরীণ শনাক্তকারী সিম্বল দিয়ে, `I18nErrorBase` থেকে উত্তরাধিকারী নয় এমন ক্লাসের মিশ্রণ টাইপ-স্তরে রোধ করে।

## পরিপূরক [#notes]

- `message` রিজলভে ব্যবহৃত `lang`-এর ডিফল্ট মান `"en"`। `setGlobalConfig({ lang })` দিয়ে স্পষ্টভাবে বদলান
- ভাষা কোড স্বাভাবিককরণ বা ফলব্যাক চেইন নেই (যেমন: `en-US` থেকে `en`-এ অব্যাহতি)। অনিবন্ধিত ভাষা একভাবে ডিফল্ট বার্তা হয়
- নিবন্ধন ডেটা প্রক্রিয়া-ব্যাপী `WeakMap`-এ সংরক্ষিত। পরীক্ষায় আলাদা করতে চাইলে `globalThis.i18n_error_base__message_map = undefined` দিয়ে ধ্বংস করা যায়
