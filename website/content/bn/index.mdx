Valibot-এর গ্লোবাল ভাষা সেটিং (`lang`)-এর সাথে `message` গতিশীলভাবে বদলে দেয়, `Error` উত্তরাধিকারের জন্য বেস ক্লাস।

```ts
import { setGlobalConfig } from "valibot";
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";

class NotFoundError extends I18nErrorBase<{ resource: string }> {}

setErrorMessage(NotFoundError, ({ resource }) => `リソースが見つかりません: ${resource}`, "ja");
setErrorMessage(NotFoundError, ({ resource }) => `Resource not found: ${resource}`, "en");

const error = new NotFoundError({ resource: "user" }, "fallback message");

setGlobalConfig({ lang: "ja" });
console.log(error.message); // リソースが見つかりません: user

setGlobalConfig({ lang: "en" });
console.log(error.message); // Resource not found: user
```

`message` অ্যাক্সেসের সময় সেই মুহূর্তের `lang` দেখা হয় বলে, ইনস্ট্যান্স নতুন করে না বানিয়েও ভাষা বদলানো যায়। নিবন্ধন নেই এমন ভাষায় কনস্ট্রাক্টরে দেওয়া ডিফল্ট বার্তায় ফলব্যাক করে।

## বৈশিষ্ট্য [#features]

- Valibot-এর `getGlobalConfig()` / `setGlobalConfig({ lang })`-এর সাথে যুক্ত হয়ে `message` গতিশীলভাবে রিজলভ করে
- প্রতিটি ভাষার বার্তা `setErrorMessage` দিয়ে পরে নিবন্ধন করা হয়। `meta` গ্রহণকারী ফাংশনও নিবন্ধন করা যায়
- নিবন্ধন নেই এমন ভাষায় কনস্ট্রাক্টরের ডিফল্ট বার্তায় ফলব্যাক করে
- ক্লাস-প্রতি `static prefix` দিয়ে বার্তার শুরুতে উপসর্গ যোগ করা যায়
- `meta` কনস্ট্রাক্টরে সংরক্ষণ করে বার্তা তৈরির ফাংশনে পাঠায়
- `Error` থেকে উত্তরাধিকার সূত্রে পাওয়ায় `instanceof Error`, `cause`, `stack` যথাযথভাবে ব্যবহার করা যায়
- বার্তার সংরক্ষণস্থল `WeakMap` হওয়ায়, অপ্রয়োজনীয় ক্লাস গারবেজ-কালেক্ট হয়

## কার্যপ্রণালী [#how-it-works]

`I18nErrorBase`-এর কনস্ট্রাক্টর `message`-কে গেটার হিসেবে সংজ্ঞায়িত করে। প্রতিটি অ্যাক্সেসে নিচের ক্রমে রিজলভ করে।

1. `getGlobalConfig()` থেকে `lang` নেয়। সেট না থাকলে `"en"`
2. `setErrorMessage` দিয়ে নিবন্ধিত `(ক্লাস × lang)` ফাংশন থাকলে `meta` দিয়ে চালায়
3. না থাকলে কনস্ট্রাক্টরে দেওয়া স্ট্রিং বা ফাংশনের ফলাফল (ডিফল্ট বার্তা) ফেরত দেয়
4. `static prefix` সেট থাকলে শুরুতে যুক্ত করে

:::tip
ডিফল্ট বার্তার ফাংশন রূপ প্রথম অ্যাক্সেসে মূল্যায়ন হয়, এরপর ক্যাশ হয়। নিবন্ধিত ভাষার বার্তা প্রতিটি অ্যাক্সেসে `meta` থেকে পুনরায় তৈরি হয় বলে, ভাষা বদল তাৎক্ষণিক প্রতিফলিত হয়।
:::
