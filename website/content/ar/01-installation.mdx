## المتطلبات [#requirements]

- بيئة تنفيذ قادرة على التعامل مع وحدات ES مثل Node.js
- يلزم `valibot@^1.0.0` كاعتمادية نظير

`message` تتبع `lang` من `getGlobalConfig()` في Valibot.

## التثبيت [#installation]

```package-install
npm i i18n-error-base
```

إذا لم يكن Valibot مثبتًا بعد، فأضفه معها.

```package-install
npm i valibot
```

:::warning[تنبيه بشأن اعتمادية النظير]
`valibot` غير مضمّنة. بدون `valibot@^1.0.0` يفشل حلّ الاستيراد.
:::

## الاستيراد [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```
