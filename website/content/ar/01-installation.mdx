## المتطلبات [#requirements]

- بيئة تنفيذ قادرة على التعامل مع وحدات ES مثل Node.js
- يلزم `valibot@^1.0.0` كاعتمادية نظير

يرجع `I18nErrorBase` داخليًا إلى `getGlobalConfig()` في Valibot للحصول على `lang` الحالية. وحتى في المشاريع التي لا تستخدم Valibot، يكفي استدعاء `setGlobalConfig({ lang })` لغرض تبديل اللغة لكي يعمل.

## التثبيت [#installation]

```package-install
npm i i18n-error-base
```

إذا لم يكن Valibot مثبتًا بعد، فأضفه معها.

```package-install
npm i valibot
```

:::warning[تنبيه بشأن اعتمادية النظير]
لا تُضمِّن `i18n-error-base` الحزمة `valibot`. فإذا لم يوفِّر المشروع المضيف `valibot@^1.0.0`، فسيفشل حلّ الاستيراد.
:::

## الاستيراد [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```

يتوفر أيضًا تصدير افتراضي.

```ts
import I18nErrorBase from "i18n-error-base";
import setErrorMessage from "i18n-error-base";
```

:::note
تُوزَّع الحزمة بصيغة ESM (`"type": "module"`) دون آثار جانبية (`"sideEffects": false`). وتُحَلّ تعريفات الأنواع من `dist/src/*.d.ts`.
:::
