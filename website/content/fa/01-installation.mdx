## پیش‌نیازها [#requirements]

- محیط اجرایی که بتواند ماژول‌های ES را مدیریت کند، مانند Node.js
- به‌عنوان وابستگی همتا (peer) به `valibot@^1.0.0` نیاز است

`message` از `lang` در `getGlobalConfig()` والیبوت پیروی می‌کند.

## نصب [#installation]

```package-install
npm i i18n-error-base
```

اگر Valibot هنوز نصب نشده است، آن را هم اضافه کنید.

```package-install
npm i valibot
```

:::warning[توجه به وابستگی همتا]
`valibot` باندل نمی‌شود. بدون `valibot@^1.0.0` ایمپورت ناموفق است.
:::

## ایمپورت [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```
