## `I18nErrorBase` [#i18n-error-base]

`Error`를 상속하기 위한 베이스 클래스입니다. `message`를 게터로 재정의하고, Valibot의 `lang`에 따라 동적으로 해결합니다.

```ts
import { I18nErrorBase } from "i18n-error-base";

class MyError extends I18nErrorBase<{ code: string }> {}
```

### 타입 매개변수 [#type-params]

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `TMeta` | `ErrorMeta \| undefined` | `ErrorMeta \| undefined` | `meta`로 보관하는 부가 정보의 타입입니다. 사용하지 않는 경우 `undefined`를 지정합니다. |

### 정적 속성 [#static-props]

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `prefix?` | `string` | `undefined` | 설정하면 해결된 메시지 앞에 연결됩니다. |

### 인스턴스 속성 [#instance-props]

| Prop | Type | Description |
| ---- | ---- | ----------- |
| `meta` | `TMeta` | 생성자에서 전달한 부가 정보입니다. 읽고 쓸 수 있습니다. |
| `message` | `string` | 현재 `lang`에 따라 해결되는 메시지입니다. 열거 가능합니다. |
| `cause` | `unknown` | `ErrorOptions`로 전달한 원인입니다. `Error`의 표준 속성입니다. |

### 생성자 [#constructor]

`TMeta`가 `undefined`를 포함하지 않는 경우, `meta`는 필수입니다.

```ts
new MyError(meta, message, options?)
```

`TMeta`가 `undefined`인 경우, `meta`를 생략할 수 있습니다.

```ts
new MyError(message, options?)
new MyError(meta, message, options?)
```

| 매개변수 | 타입 | 설명 |
| ------------ | -- | ---- |
| `meta` | `TMeta` | 메시지 생성에 사용하는 부가 정보입니다. |
| `message` | `string \| MessageFactory<TMeta>` | 등록되지 않은 언어에서 사용하는 기본 메시지입니다. 함수인 경우 `meta`를 받습니다. |
| `options` | `ErrorOptions` | `Error`의 두 번째 인수와 호환되는 옵션입니다(`{ cause }` 등). |

`message`에 문자열 이외의 값(숫자 등)을 전달한 경우 `String(...)`으로 문자열화됩니다. 메시지 팩토리가 빈 문자열을 반환한 경우 `message`도 빈 문자열이 됩니다.

### 해결 순서 [#resolution-order]

1. `getGlobalConfig()`의 `lang`을 가져옵니다(설정되지 않은 경우 `"en"`)
2. `setErrorMessage`로 등록된 해당 클래스·해당 언어의 함수를 `meta`와 함께 실행합니다
3. 미등록인 경우 생성자의 기본 메시지(문자열 또는 함수의 평가 결과. 첫 평가 후에는 캐시)를 사용합니다
4. `static prefix`가 있으면 앞에 연결합니다

:::note
등록 일치는 `this.constructor`의 완전 일치입니다. 부모 클래스에 대한 등록은 자식 클래스에 상속되지 않습니다. 필요한 클래스마다 등록하십시오.
:::

## `setErrorMessage` [#set-error-message]

언어별 메시지 생성 함수를 등록합니다.

```ts
import { setErrorMessage } from "i18n-error-base";

setErrorMessage(MyError, (meta) => `...: ${meta.code}`, "ja");
```

| 매개변수 | 타입 | 설명 |
| ------------ | -- | ---- |
| `reference` | `I18nErrorBaseConstructor` | `I18nErrorBase`를 상속한 클래스입니다. 상속하지 않은 클래스는 타입 오류가 됩니다. |
| `message` | `string \| (meta) => string` | 등록할 메시지입니다. `meta`의 타입은 대상 클래스의 `meta`에서 추론됩니다. |
| `lang` | `string \| Iterable<string>` | 대상 언어입니다. 단일 코드 또는 코드의 이터러블 객체(배열 등)입니다. |

문자열은 내부에서 함수로 변환하여 보관합니다. 동일한 클래스·동일한 언어에 다시 등록하면 덮어씁니다. 저장소는 `globalThis.i18n_error_base__message_map`의 `WeakMap`이며, 키는 클래스, 값은 언어에서 함수로의 `Map`입니다.

## 타입 [#types]

### `ErrorMeta` [#error-meta]

```ts
type ErrorMeta = {
  readonly [prop: string]: unknown;
};
```

`TMeta`의 기본 제약입니다. 임의의 속성을 가진 읽기 전용 객체를 나타냅니다.

### `ErrorOptions` [#error-options]

```ts
type ErrorOptions =
  ConstructorParameters<typeof Error> extends [
    message?: unknown,
    options?: (infer TOptions) | undefined,
  ]
    ? TOptions
    : { readonly cause?: unknown };
```

실행 환경의 `Error` 생성자 두 번째 인수에서 도출한 타입입니다. `cause`를 포함한 옵션을 전달할 수 있습니다. 후자의 분기는 이전 환경용 폴백입니다.

### `MessageFactory<TMeta>` [#message-factory]

```ts
interface MessageFactory<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> {
  (meta: TMeta): string;
}
```

`meta`에서 메시지를 생성하는 함수입니다. 생성자의 기본 메시지와 `setErrorMessage`의 등록 값 모두에서 사용할 수 있습니다.

### `I18nErrorBaseParams<TMeta>` [#i18n-error-base-params]

생성자 인수의 오버로드를 나타내는 타입입니다.

```ts
type I18nErrorBaseParams<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> =
  [TMeta] extends [undefined]
    ?
        | [message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
        | [meta: undefined, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
    : [meta: TMeta, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined];
```

`TMeta`가 `undefined`인 경우에만 `meta`의 생략형이 허용됩니다.

### `I18nErrorBaseConstructor` [#i18n-error-base-constructor]

```ts
interface I18nErrorBaseConstructor {
  new (...args: any): I18nErrorBase;
}
```

`setErrorMessage`의 첫 번째 인수의 타입입니다. 내부 식별용 심볼을 통해, `I18nErrorBase`를 상속하지 않는 클래스의 혼입을 타입 수준에서 방지합니다.

## 참고 [#notes]

- `message` 해결에 사용하는 `lang`의 기본값은 `"en"`입니다. `setGlobalConfig({ lang })`으로 명시적으로 전환하십시오
- 언어 코드의 정규화나 폴백 체인(예: `en-US`에서 `en`으로의 대체)은 없습니다. 미등록 언어는 일률적으로 기본 메시지가 됩니다
- 등록 데이터는 프로세스 전체의 `WeakMap`에 보관됩니다. 테스트에서 격리하려면 `globalThis.i18n_error_base__message_map = undefined`로 파기할 수 있습니다
