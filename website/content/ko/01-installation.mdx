## 요구 사항 [#requirements]

- Node.js 등 ES 모듈을 다룰 수 있는 실행 환경
- 피어 의존성으로 `valibot@^1.0.0`이 필요합니다

`message`는 Valibot `getGlobalConfig()`의 `lang`을 따릅니다.

## 설치 [#installation]

```package-install
npm i i18n-error-base
```

Valibot이 아직 설치되지 않은 경우 함께 추가하십시오.

```package-install
npm i valibot
```

:::warning[피어 의존성 주의]
`valibot`은 번들되지 않습니다. `valibot@^1.0.0`이 없으면 가져오기에 실패합니다.
:::

## 가져오기 [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```
