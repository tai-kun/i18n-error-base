Valibot의 글로벌 언어 설정(`lang`)과 연동하여 `message`를 동적으로 전환하는, `Error` 상속을 위한 베이스 클래스입니다.

```ts
import { setGlobalConfig } from "valibot";
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";

class NotFoundError extends I18nErrorBase<{ resource: string }> {}

setErrorMessage(NotFoundError, ({ resource }) => `リソースが見つかりません: ${resource}`, "ja");
setErrorMessage(NotFoundError, ({ resource }) => `Resource not found: ${resource}`, "en");

const error = new NotFoundError({ resource: "user" }, "fallback message");

setGlobalConfig({ lang: "ja" });
console.log(error.message); // リソースが見つかりません: user

setGlobalConfig({ lang: "en" });
console.log(error.message); // Resource not found: user
```

`message`에 접근할 때마다 그 시점의 `lang`을 참조하므로, 인스턴스를 다시 만들지 않고도 언어를 전환할 수 있습니다. 등록되지 않은 언어에서는 생성자에 전달한 기본 메시지로 폴백합니다.

## 특징 [#features]

- Valibot의 `getGlobalConfig()` / `setGlobalConfig({ lang })`과 연동하여 `message`를 동적으로 해결합니다
- 언어별 메시지는 `setErrorMessage`로 나중에 등록합니다. `meta`를 받는 함수도 등록할 수 있습니다
- 등록되지 않은 언어에서는 생성자의 기본 메시지로 폴백합니다
- 클래스 단위의 `static prefix`로 메시지 앞에 접두사를 추가할 수 있습니다
- `meta`를 생성자에서 보관하고 메시지 생성 함수에 전달합니다
- `Error`를 상속하므로 `instanceof Error`, `cause`, `stack`을 그대로 사용할 수 있습니다
- 메시지 저장소는 `WeakMap`이므로, 더 이상 필요 없는 클래스는 가비지 컬렉션됩니다

## 동작 방식 [#how-it-works]

`I18nErrorBase`의 생성자는 `message`를 게터로 정의합니다. 접근할 때마다 다음 순서대로 해결합니다.

1. `getGlobalConfig()`에서 `lang`을 가져옵니다. 설정되지 않은 경우는 `"en"`입니다
2. `setErrorMessage`로 등록된 (클래스 × lang) 함수가 있으면 `meta`를 전달하여 실행합니다
3. 없으면 생성자에 전달한 문자열 또는 함수의 결과(기본 메시지)를 반환합니다
4. `static prefix`가 설정되어 있으면 앞에 연결합니다

:::tip
기본 메시지의 함수 형태는 첫 접근 시에 평가되며, 이후에는 캐시됩니다. 등록된 언어의 메시지는 접근할 때마다 `meta`로부터 다시 생성되므로, 언어 전환이 즉시 반영됩니다.
:::
