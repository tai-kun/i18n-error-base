## `I18nErrorBase` [#i18n-error-base]

`Error` को विस्तारित करने के लिए आधार वर्ग है। `message` को गेटर के रूप में पुनः परिभाषित करता है और Valibot के `lang` के अनुसार गतिशील रूप से हल करता है।

```ts
import { I18nErrorBase } from "i18n-error-base";

class MyError extends I18nErrorBase<{ code: string }> {}
```

### प्रकार पैरामीटर [#type-params]

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `TMeta` | `ErrorMeta \| undefined` | `ErrorMeta \| undefined` | `meta` के रूप में रखी जाने वाली सहायक जानकारी का प्रकार। उपयोग न करने पर `undefined` निर्दिष्ट करें। |

### स्थैतिक गुण [#static-props]

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `prefix?` | `string` | `undefined` | सेट करने पर हल किए गए संदेश की शुरुआत में जोड़ा जाता है। |

### इंस्टेंस गुण [#instance-props]

| Prop | Type | Description |
| ---- | ---- | ----------- |
| `meta` | `TMeta` | कंस्ट्रक्टर में दी गई सहायक जानकारी। पठनीय और लेखनीय है। |
| `message` | `string` | वर्तमान `lang` के अनुसार हल किया गया संदेश। गणनीय है। |
| `cause` | `unknown` | `ErrorOptions` से दिया गया कारण। `Error` का मानक गुण है। |

### कंस्ट्रक्टर [#constructor]

`TMeta` में `undefined` शामिल न होने पर, `meta` आवश्यक है।

```ts
new MyError(meta, message, options?)
```

`TMeta` के `undefined` होने पर, `meta` छोड़ा जा सकता है।

```ts
new MyError(message, options?)
new MyError(meta, message, options?)
```

| पैरामीटर | प्रकार | विवरण |
| ------------ | -- | ---- |
| `meta` | `TMeta` | संदेश निर्माण में उपयोग की जाने वाली सहायक जानकारी। |
| `message` | `string \| MessageFactory<TMeta>` | अपंजीकृत भाषा में उपयोग किया जाने वाला डिफ़ॉल्ट संदेश। फ़ंक्शन होने पर `meta` प्राप्त करता है। |
| `options` | `ErrorOptions` | `Error` के दूसरे तर्क के साथ संगत विकल्प (`{ cause }` आदि)। |

`message` में स्ट्रिंग के अलावा (संख्या आदि) देने पर `String(...)` से स्ट्रिंग में बदला जाता है। संदेश फ़ैक्टरी के खाली स्ट्रिंग लौटाने पर `message` भी खाली स्ट्रिंग होता है।

### समाधान क्रम [#resolution-order]

1. `getGlobalConfig()` का `lang` प्राप्त करता है (सेट न होने पर `"en"`)
2. `setErrorMessage` से पंजीकृत संबंधित वर्ग・संबंधित भाषा के फ़ंक्शन को `meta` सहित निष्पादित करता है
3. अपंजीकृत होने पर कंस्ट्रक्टर के डिफ़ॉल्ट संदेश (स्ट्रिंग या फ़ंक्शन के मूल्यांकन परिणाम। पहले मूल्यांकन के बाद कैश) का उपयोग करता है
4. `static prefix` होने पर शुरुआत में जोड़ता है

:::note
पंजीकरण का मिलान `this.constructor` की पूर्ण समानता से होता है। मूल वर्ग में पंजीकरण उपवर्ग में विरासत में नहीं मिलता। आवश्यक प्रत्येक वर्ग में पंजीकृत करें।
:::

## `setErrorMessage` [#set-error-message]

प्रत्येक भाषा का संदेश निर्माण फ़ंक्शन पंजीकृत करता है।

```ts
import { setErrorMessage } from "i18n-error-base";

setErrorMessage(MyError, (meta) => `...: ${meta.code}`, "ja");
```

| पैरामीटर | प्रकार | विवरण |
| ------------ | -- | ---- |
| `reference` | `I18nErrorBaseConstructor` | `I18nErrorBase` को विस्तारित करने वाला वर्ग। विस्तारित न करने वाले वर्ग प्रकार त्रुटि होते हैं। |
| `message` | `string \| (meta) => string` | पंजीकृत किया जाने वाला संदेश। `meta` का प्रकार लक्षित वर्ग के `meta` से अनुमानित होता है। |
| `lang` | `string \| Iterable<string>` | लक्षित भाषा। एकल कोड या कोड की पुनरावर्तनीय वस्तु (ऐरे आदि)। |

स्ट्रिंग आंतरिक रूप से फ़ंक्शन में बदलकर रखी जाती है। समान वर्ग・समान भाषा में पुनः पंजीकरण अधिलेखन होता है। भंडारण स्थान `globalThis.i18n_error_base__message_map` का `WeakMap` है, कुंजी वर्ग और मान भाषा से फ़ंक्शन तक का `Map` है।

## प्रकार [#types]

### `ErrorMeta` [#error-meta]

```ts
type ErrorMeta = {
  readonly [prop: string]: unknown;
};
```

`TMeta` की डिफ़ॉल्ट बाध्यता है। मनमाने गुणों वाली केवल-पठनीय वस्तु को दर्शाता है।

### `ErrorOptions` [#error-options]

```ts
type ErrorOptions =
  ConstructorParameters<typeof Error> extends [
    message?: unknown,
    options?: (infer TOptions) | undefined,
  ]
    ? TOptions
    : { readonly cause?: unknown };
```

निष्पादन वातावरण के `Error` कंस्ट्रक्टर के दूसरे तर्क से व्युत्पन्न प्रकार है। `cause` सहित विकल्प दिया जा सकता है। बाद वाली शाखा पुराने वातावरण के लिए फ़ॉलबैक है।

### `MessageFactory<TMeta>` [#message-factory]

```ts
interface MessageFactory<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> {
  (meta: TMeta): string;
}
```

`meta` से संदेश बनाने वाला फ़ंक्शन है। कंस्ट्रक्टर के डिफ़ॉल्ट संदेश और `setErrorMessage` के पंजीकृत मान दोनों में उपयोग किया जा सकता है।

### `I18nErrorBaseParams<TMeta>` [#i18n-error-base-params]

कंस्ट्रक्टर तर्कों के ओवरलोड को दर्शाने वाला प्रकार है।

```ts
type I18nErrorBaseParams<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> =
  [TMeta] extends [undefined]
    ?
        | [message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
        | [meta: undefined, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
    : [meta: TMeta, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined];
```

`TMeta` के `undefined` होने पर ही `meta` का संक्षिप्त रूप अनुमत होता है।

### `I18nErrorBaseConstructor` [#i18n-error-base-constructor]

```ts
interface I18nErrorBaseConstructor {
  new (...args: any): I18nErrorBase;
}
```

`setErrorMessage` के पहले तर्क का प्रकार है। आंतरिक पहचान प्रतीक द्वारा, `I18nErrorBase` को विस्तारित न करने वाले वर्गों के मिश्रण को प्रकार स्तर पर रोकता है।

## पूरक [#notes]

- `message` के समाधान में उपयोग किए जाने वाले `lang` का डिफ़ॉल्ट मान `"en"` है। `setGlobalConfig({ lang })` से स्पष्ट रूप से बदलें
- भाषा कोड का सामान्यीकरण या फ़ॉलबैक श्रृंखला (उदा.: `en-US` से `en` में वापसी) नहीं है। अपंजीकृत भाषाएँ एक समान डिफ़ॉल्ट संदेश बन जाती हैं
- पंजीकृत डेटा प्रक्रिया-व्यापी `WeakMap` में रखा जाता है। परीक्षण में पृथक करना हो तो `globalThis.i18n_error_base__message_map = undefined` से नष्ट किया जा सकता है
