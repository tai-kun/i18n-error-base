## आवश्यकताएँ [#requirements]

- Node.js आदि ES मॉड्यूल संभाल सकने वाला निष्पादन वातावरण
- peer निर्भरता के रूप में `valibot@^1.0.0` आवश्यक है

`message` Valibot के `getGlobalConfig()` के `lang` का अनुसरण करता है।

## इंस्टॉलेशन [#installation]

```package-install
npm i i18n-error-base
```

Valibot इंस्टॉल न होने पर साथ में जोड़ें।

```package-install
npm i valibot
```

:::warning[peer निर्भरता पर ध्यान दें]
`valibot` बंडल नहीं है। `valibot@^1.0.0` के बिना आयात विफल होता है।
:::

## आयात [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```
