## Requisitos [#requirements]

- Un entorno de ejecución como Node.js que pueda manejar módulos ES
- Se requiere `valibot@^1.0.0` como dependencia peer

`I18nErrorBase` consulta internamente `getGlobalConfig()` de Valibot para obtener el `lang` actual. Incluso en proyectos que no usan Valibot, basta con llamar a `setGlobalConfig({ lang })` solo para cambiar el idioma.

## Instalación [#installation]

```package-install
npm i i18n-error-base
```

Si Valibot aún no está instalado, añádalo también.

```package-install
npm i valibot
```

:::warning[Atención a la dependencia peer]
`i18n-error-base` no incluye `valibot`. Si el lado anfitrión no proporciona `valibot@^1.0.0`, se producirá un error de resolución al importar.
:::

## Importación [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```

También se proporcionan exportaciones predeterminadas.

```ts
import I18nErrorBase from "i18n-error-base";
import setErrorMessage from "i18n-error-base";
```

:::note
El paquete se distribuye como ESM (`"type": "module"`) y no tiene efectos secundarios (`"sideEffects": false`). Las definiciones de tipos se resuelven desde `dist/src/*.d.ts`.
:::
