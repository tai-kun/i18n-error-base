מחלקת בסיס לירושת `Error`, המחליפה באופן דינמי את `message` בהתאם להגדרת השפה הגלובלית (`lang`) של Valibot.

```ts
import { setGlobalConfig } from "valibot";
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";

class NotFoundError extends I18nErrorBase<{ resource: string }> {}

setErrorMessage(NotFoundError, ({ resource }) => `リソースが見つかりません: ${resource}`, "ja");
setErrorMessage(NotFoundError, ({ resource }) => `Resource not found: ${resource}`, "en");

const error = new NotFoundError({ resource: "user" }, "fallback message");

setGlobalConfig({ lang: "ja" });
console.log(error.message); // リソースが見つかりません: user

setGlobalConfig({ lang: "en" });
console.log(error.message); // Resource not found: user
```

מכיוון ש-`lang` העדכני נקרא בכל גישה ל-`message`, ניתן להחליף שפה ללא יצירה מחדש של המופע. עבור שפה שלא נרשמה, מתבצעת נפילה חזרה (fallback) להודעת ברירת המחדל שהועברה לקונסטרקטור.

## תכונות [#features]

- פותר את `message` באופן דינמי בשילוב עם `getGlobalConfig()` / `setGlobalConfig({ lang })` של Valibot
- הודעות לכל שפה נרשמות לאחר מכן באמצעות `setErrorMessage`. ניתן לרשום גם פונקציה המקבלת `meta`
- עבור שפה שלא נרשמה, מתבצע fallback להודעת ברירת המחדל של הקונסטרקטור
- ניתן להוסיף תחילית לתחילת ההודעה באמצעות `static prefix` ברמת המחלקה
- שומר את `meta` בקונסטרקטור ומעביר אותו לפונקציית יצירת ההודעה
- מכיוון שהמחלקה יורשת מ-`Error`, ניתן להשתמש כמות שהם ב-`instanceof Error`, ב-`cause` וב-`stack`
- ההודעות נשמרות ב-`WeakMap`, ולכן מחלקות שאינן נחוצות עוד עוברות garbage collection

## איך זה עובד [#how-it-works]

הקונסטרקטור של `I18nErrorBase` מגדיר את `message` כ-getter. בכל גישה הוא נפתר לפי הסדר הבא.

1. מקבל את `lang` מתוך `getGlobalConfig()`. אם לא הוגדר, ברירת המחדל היא `"en"`
2. אם קיימת פונקציה שנרשמה באמצעות `setErrorMessage` עבור (מחלקה × `lang`), מפעיל אותה עם `meta`
3. אם לא, מחזיר את המחרוזת שהועברה לקונסטרקטור או את תוצאת הפונקציה (הודעת ברירת המחדל)
4. אם הוגדר `static prefix`, משרשר אותו לתחילת ההודעה

:::tip
צורת הפונקציה של הודעת ברירת המחדל מוערכת בגישה הראשונה ומאז נשמרת במטמון. הודעות של שפות רשומות נוצרות מחדש מ-`meta` בכל גישה, ולכן החלפת השפה משתקפת באופן מיידי.
:::
