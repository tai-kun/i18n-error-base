## דרישות [#requirements]

- סביבת הרצה המסוגלת לטפל במודולי ES, כגון Node.js
- נדרשת תלות peer של `valibot@^1.0.0`

`I18nErrorBase` מתייחס פנימית ל-`getGlobalConfig()` של Valibot כדי לקבל את `lang` העדכני. גם בפרויקט שאינו משתמש ב-Valibot, ניתן להפעיל זאת פשוט על ידי קריאה ל-`setGlobalConfig({ lang })` לצורך החלפת שפה.

## התקנה [#installation]

```package-install
npm i i18n-error-base
```

אם Valibot טרם הותקן, הוסיפו אותו יחד.

```package-install
npm i valibot
```

:::warning[שימו לב לתלות ה-peer]
`i18n-error-base` אינו מאגד בתוכו את `valibot`. אם הצד המארח אינו מספק את `valibot@^1.0.0`, תתקבל שגיאת resolution בעת הייבוא.
:::

## ייבוא [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```

קיים גם ייצוא ברירת מחדל.

```ts
import I18nErrorBase from "i18n-error-base";
import setErrorMessage from "i18n-error-base";
```

:::note
החבילה מופצת כ-ESM (`"type": "module"`) ללא תופעות לוואי (`"sideEffects": false`). הגדרות הטיפוסים נפתרות מתוך `dist/src/*.d.ts`.
:::
