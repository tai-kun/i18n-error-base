## `I18nErrorBase` [#i18n-error-base]

Основна класа за наслеђивање класе `Error`. Поново дефинише `message` као гетер и динамички га разрешава према Valibot подешавању `lang`.

```ts
import { I18nErrorBase } from "i18n-error-base";

class MyError extends I18nErrorBase<{ code: string }> {}
```

### Параметри типа [#type-params]

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `TMeta` | `ErrorMeta \| undefined` | `ErrorMeta \| undefined` | Тип пратећих информација које се чувају као `meta`. Ако се не користи, наведите `undefined`. |

### Статичка својства [#static-props]

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `prefix?` | `string` | `undefined` | Ако се подеси, додаје се на почетак разрешене поруке. |

### Својства инстанце [#instance-props]

| Prop | Type | Description |
| ---- | ---- | ----------- |
| `meta` | `TMeta` | Пратеће информације прослеђене конструктору. Могу се читати и писати. |
| `message` | `string` | Порука разрешена према тренутном `lang`. Може се набрајати. |
| `cause` | `unknown` | Узрок прослеђен путем `ErrorOptions`. Стандардно својство класе `Error`. |

### Конструктор [#constructor]

Ако `TMeta` не укључује `undefined`, `meta` је обавезан.

```ts
new MyError(meta, message, options?)
```

Ако је `TMeta` типа `undefined`, `meta` се може изоставити.

```ts
new MyError(message, options?)
new MyError(meta, message, options?)
```

| Параметар | Тип | Опис |
| --------- | --- | ---- |
| `meta` | `TMeta` | Пратеће информације које се користе за генерисање поруке. |
| `message` | `string \| MessageFactory<TMeta>` | Подразумевана порука која се користи за језике без регистрације. Ако је функција, прима `meta`. |
| `options` | `ErrorOptions` | Опције компатибилне са другим аргументом конструктора `Error` (нпр. `{ cause }`). |

Ако се за `message` проследи нешто што није стринг (нпр. број), претвара се у стринг помоћу `String(...)`. Ако функција за израду поруке врати празан стринг, и `message` ће бити празан стринг.

### Редослед разрешавања [#resolution-order]

1. Преузима `lang` из `getGlobalConfig()` (када није подешено, `"en"`)
2. Извршава функцију за дату класу и дати језик регистровану помоћу `setErrorMessage`, са прослеђеним `meta`
3. Ако није регистровано, користи подразумевану поруку из конструктора (стринг или резултат процене функције; након прве процене чува се у кешу)
4. Ако постоји `static prefix`, додаје се на почетак

:::note
Подударање регистрације је строго поклапање са `this.constructor`. Регистрација у родитељској класи не наслеђује се у подређену класу. Региструјте поруку за сваку потребну класу.
:::

## `setErrorMessage` [#set-error-message]

Региструје функцију за израду поруке за сваки језик.

```ts
import { setErrorMessage } from "i18n-error-base";

setErrorMessage(MyError, (meta) => `...: ${meta.code}`, "ja");
```

| Параметар | Тип | Опис |
| --------- | --- | ---- |
| `reference` | `I18nErrorBaseConstructor` | Класа која наслеђује `I18nErrorBase`. Класе које га не наслеђују изазивају грешку типа. |
| `message` | `string \| (meta) => string` | Порука за регистрацију. Тип `meta` изводи се из `meta` циљане класе. |
| `lang` | `string \| Iterable<string>` | Циљани језик. Један језички код или итерабилни објекат кодова (нпр. низ). |

Стрингови се интерно претварају у функције и чувају. Поновна регистрација за исту класу и исти језик преписује претходну вредност. Чува се у `WeakMap`-у на `globalThis.i18n_error_base__message_map`, при чему је кључ класа, а вредност `Map` од језика до функције.

## Типови [#types]

### `ErrorMeta` [#error-meta]

```ts
type ErrorMeta = {
  readonly [prop: string]: unknown;
};
```

Подразумевано ограничење за `TMeta`. Представља објекат само за читање са произвољним својствима.

### `ErrorOptions` [#error-options]

```ts
type ErrorOptions =
  ConstructorParameters<typeof Error> extends [
    message?: unknown,
    options?: (infer TOptions) | undefined,
  ]
    ? TOptions
    : { readonly cause?: unknown };
```

Тип изведен из другог аргумента конструктора `Error` у извршном окружењу. Могу се проследити опције које садрже `cause`. Друга грана је резервна вредност за старија окружења.

### `MessageFactory<TMeta>` [#message-factory]

```ts
interface MessageFactory<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> {
  (meta: TMeta): string;
}
```

Функција која генерише поруку из `meta`. Може се користити и као подразумевана порука конструктора и као регистрована вредност у `setErrorMessage`.

### `I18nErrorBaseParams<TMeta>` [#i18n-error-base-params]

Тип који представља преоптерећења аргумената конструктора.

```ts
type I18nErrorBaseParams<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> =
  [TMeta] extends [undefined]
    ?
        | [message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
        | [meta: undefined, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
    : [meta: TMeta, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined];
```

Скраћени облик без `meta` дозвољен је само када је `TMeta` типа `undefined`.

### `I18nErrorBaseConstructor` [#i18n-error-base-constructor]

```ts
interface I18nErrorBaseConstructor {
  new (...args: any): I18nErrorBase;
}
```

Тип првог аргумента методе `setErrorMessage`. Интерним симболом за идентификацију спречава се на нивоу типа мешање класа које не наслеђују `I18nErrorBase`.

## Напомене [#notes]

- Подразумевана вредност `lang` која се користи за разрешавање `message` је `"en"`. Изричито промените помоћу `setGlobalConfig({ lang })`
- Нема нормализације језичких кодова ни ланца заменских језика (нпр. повратак са `en-US` на `en`). Нерегистровани језици увек дају подразумевану поруку
- Регистровани подаци чувају се у `WeakMap`-у целог процеса. Ако их желите изоловати у тестовима, можете их одбацити са `globalThis.i18n_error_base__message_map = undefined`
