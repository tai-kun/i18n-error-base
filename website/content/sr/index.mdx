Основна класа за наслеђивање класе `Error` која динамички пребацује `message` у складу са глобалним језичким подешавањем Valibot-а (`lang`).

```ts
import { setGlobalConfig } from "valibot";
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";

class NotFoundError extends I18nErrorBase<{ resource: string }> {}

setErrorMessage(NotFoundError, ({ resource }) => `リソースが見つかりません: ${resource}`, "ja");
setErrorMessage(NotFoundError, ({ resource }) => `Resource not found: ${resource}`, "en");

const error = new NotFoundError({ resource: "user" }, "fallback message");

setGlobalConfig({ lang: "ja" });
console.log(error.message); // リソースが見つかりません: user

setGlobalConfig({ lang: "en" });
console.log(error.message); // Resource not found: user
```

Пошто се при приступу својству `message` чита тренутни `lang`, језик се може променити без поновног стварања инстанце. За језике без регистрације користи се подразумевана порука прослеђена конструктору.

## Карактеристике [#features]

- Повезује се са Valibot методама `getGlobalConfig()` / `setGlobalConfig({ lang })` и динамички разрешава `message`
- Поруке за сваки језик накнадно се региструју помоћу `setErrorMessage`. Могу се регистровати и функције које примају `meta`
- За језике без регистрације користи се подразумевана порука из конструктора
- Помоћу `static prefix` по класи може се додати префикс на почетак поруке
- `meta` се чува у конструктору и прослеђује функцији за генерисање поруке
- Пошто наслеђује `Error`, `instanceof Error`, `cause` и `stack` могу се користити непосредно
- Поруке се чувају у `WeakMap`-у, па се непотребне класе уклањају сакупљачем отпада

## Како ради [#how-it-works]

Конструктор класе `I18nErrorBase` дефинише `message` као гетер. При сваком приступу разрешава се следећим редоследом.

1. Преузима `lang` из `getGlobalConfig()`. Ако није подешено, вредност је `"en"`
2. Ако постоји функција `(класа × lang)` регистрована помоћу `setErrorMessage`, извршава се са прослеђеним `meta`
3. У супротном враћа стринг прослеђен конструктору или резултат функције (подразумевана порука)
4. Ако је подешен `static prefix`, додаје се на почетак

:::tip
Функцијски облик подразумеване поруке процењује се при првом приступу и потом се чува у кешу. Поруке регистрованих језика поново се генеришу из `meta` при сваком приступу, па се промена језика одражава одмах.
:::
