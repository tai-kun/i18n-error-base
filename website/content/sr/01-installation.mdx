## Захтеви [#requirements]

- Извршно окружење које може да рукује ES модулима, попут Node.js
- Као peer зависност потребан је `valibot@^1.0.0`

`message` прати `lang` из Valibot методе `getGlobalConfig()`.

## Инсталација [#installation]

```package-install
npm i i18n-error-base
```

Ако Valibot још није инсталиран, додајте га заједно.

```package-install
npm i valibot
```

:::warning[Пажња на peer зависност]
`valibot` није укључен. Без `valibot@^1.0.0` увоз се не може разрешити.
:::

## Увоз [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```
