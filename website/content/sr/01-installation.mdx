## Захтеви [#requirements]

- Извршно окружење које може да рукује ES модулима, попут Node.js
- Као peer зависност потребан је `valibot@^1.0.0`

`I18nErrorBase` интерно чита Valibot методу `getGlobalConfig()` како би преузео тренутни `lang`. Чак и у пројектима који не користе Valibot, довољно је позвати `setGlobalConfig({ lang })` само ради промене језика.

## Инсталација [#installation]

```package-install
npm i i18n-error-base
```

Ако Valibot још није инсталиран, додајте га заједно.

```package-install
npm i valibot
```

:::warning[Пажња на peer зависност]
`i18n-error-base` не укључује `valibot`. Ако домаћин не припреми `valibot@^1.0.0`, доћи ће до грешке разрешавања при увозу.
:::

## Увоз [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```

Доступан је и подразумевани извоз.

```ts
import I18nErrorBase from "i18n-error-base";
import setErrorMessage from "i18n-error-base";
```

:::note
Пакет се дистрибуира као ESM (`"type": "module"`) и нема нуспојаве (`"sideEffects": false`). Дефиниције типова разрешавају се из `dist/src/*.d.ts`.
:::
