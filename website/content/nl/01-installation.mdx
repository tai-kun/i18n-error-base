## Vereisten [#requirements]

- Een runtime die ES-modules kan verwerken, zoals Node.js
- `valibot@^1.0.0` is vereist als peer-afhankelijkheid

`I18nErrorBase` verwijst intern naar Valibot's `getGlobalConfig()` om de huidige `lang` op te halen. Zelfs in projecten die Valibot verder niet gebruiken, volstaat het om `setGlobalConfig({ lang })` aan te roepen puur om van taal te wisselen.

## Installatie [#installation]

```package-install
npm i i18n-error-base
```

Als Valibot nog niet is geïnstalleerd, voeg deze dan ook toe.

```package-install
npm i valibot
```

:::warning[Let op de peer-afhankelijkheid]
`i18n-error-base` bundelt `valibot` niet. Als de host geen `valibot@^1.0.0` levert, mislukt de resolutie van de import.
:::

## Importeren [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```

Er is ook een default-export beschikbaar.

```ts
import I18nErrorBase from "i18n-error-base";
import setErrorMessage from "i18n-error-base";
```

:::note
Het pakket wordt als ESM (`"type": "module"`) gedistribueerd en heeft geen bijwerkingen (`"sideEffects": false`). Typedefinities worden uit `dist/src/*.d.ts` opgelost.
:::
