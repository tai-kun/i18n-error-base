## Vereisten [#requirements]

- Een runtime die ES-modules kan verwerken, zoals Node.js
- `valibot@^1.0.0` is vereist als peer-afhankelijkheid

`message` volgt `lang` uit Valibot's `getGlobalConfig()`.

## Installatie [#installation]

```package-install
npm i i18n-error-base
```

Als Valibot nog niet is geïnstalleerd, voeg deze dan ook toe.

```package-install
npm i valibot
```

:::warning[Let op de peer-afhankelijkheid]
`valibot` wordt niet gebundeld. Zonder `valibot@^1.0.0` mislukt de resolutie van de import.
:::

## Importeren [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```
