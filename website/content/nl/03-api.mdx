## `I18nErrorBase` [#i18n-error-base]

De basisklasse om `Error` te overerven. Herdefinieert `message` als een getter en lost deze dynamisch op afhankelijk van Valibot's `lang`.

```ts
import { I18nErrorBase } from "i18n-error-base";

class MyError extends I18nErrorBase<{ code: string }> {}
```

### Typeparameters [#type-params]

| Prop | Type | Default | Beschrijving |
| ---- | ---- | ------- | ------------ |
| `TMeta` | `ErrorMeta \| undefined` | `ErrorMeta \| undefined` | Het type van de aanvullende informatie die als `meta` wordt bewaard. Geef `undefined` op als je deze niet gebruikt. |

### Statische properties [#static-props]

| Prop | Type | Default | Beschrijving |
| ---- | ---- | ------- | ------------ |
| `prefix?` | `string` | `undefined` | Wanneer ingesteld, wordt deze vooraan het opgeloste bericht samengevoegd. |

### Instantieproperties [#instance-props]

| Prop | Type | Beschrijving |
| ---- | ---- | ------------ |
| `meta` | `TMeta` | De aanvullende informatie die in de constructor is doorgegeven. Leesbaar en schrijfbaar. |
| `message` | `string` | Het bericht dat afhankelijk van de huidige `lang` wordt opgelost. Enumerable. |
| `cause` | `unknown` | De oorzaak die via `ErrorOptions` is doorgegeven. Een standaardproperty van `Error`. |

### Constructor [#constructor]

Als `TMeta` geen `undefined` bevat, is `meta` verplicht.

```ts
new MyError(meta, message, options?)
```

Als `TMeta` `undefined` is, kun je `meta` weglaten.

```ts
new MyError(message, options?)
new MyError(meta, message, options?)
```

| Parameter | Type | Beschrijving |
| --------- | ---- | ------------ |
| `meta` | `TMeta` | Aanvullende informatie voor het genereren van berichten. |
| `message` | `string \| MessageFactory<TMeta>` | Het standaardbericht voor talen zonder registratie. Als het een functie is, ontvangt deze `meta`. |
| `options` | `ErrorOptions` | Opties die compatibel zijn met het tweede argument van `Error` (zoals `{ cause }`). |

Als aan `message` iets anders dan een tekenreeks (bijv. een getal) wordt doorgegeven, wordt het met `String(...)` naar een tekenreeks omgezet. Als een berichtfabriek een lege tekenreeks teruggeeft, is `message` ook een lege tekenreeks.

### Oplossingsvolgorde [#resolution-order]

1. Haalt `lang` op uit `getGlobalConfig()` (standaard `"en"` indien niet ingesteld)
2. Voert de functie voor die klasse en taal, geregistreerd met `setErrorMessage`, uit met `meta`
3. Indien niet geregistreerd, wordt het standaardbericht uit de constructor gebruikt (een tekenreeks of het evaluatieresultaat van een functie; na de eerste evaluatie gecachet)
4. Indien `static prefix` bestaat, wordt deze vooraan samengevoegd

:::note
De registratiematch is een exacte overeenkomst met `this.constructor`. Registraties op een bovenliggende klasse worden niet overgeërfd door subklassen. Registreer voor elke benodigde klasse afzonderlijk.
:::

## `setErrorMessage` [#set-error-message]

Registreert een berichtgenererende functie per taal.

```ts
import { setErrorMessage } from "i18n-error-base";

setErrorMessage(MyError, (meta) => `...: ${meta.code}`, "ja");
```

| Parameter | Type | Beschrijving |
| --------- | ---- | ------------ |
| `reference` | `I18nErrorBaseConstructor` | Een klasse die `I18nErrorBase` overerft. Klassen zonder deze overerving veroorzaken een typefout. |
| `message` | `string \| (meta) => string` | Het te registreren bericht. Het type van `meta` wordt afgeleid uit de `meta` van de doelklasse. |
| `lang` | `string \| Iterable<string>` | De doeltaal. Eén enkele code of een itereerbaar object met codes (zoals een array). |

Tekenreeksen worden intern omgezet naar functies en bewaard. Opnieuw registreren voor dezelfde klasse en taal overschrijft. De opslag is een `WeakMap` in `globalThis.i18n_error_base__message_map`, met als sleutel de klasse en als waarde een `Map` van taal naar functie.

## Typen [#types]

### `ErrorMeta` [#error-meta]

```ts
type ErrorMeta = {
  readonly [prop: string]: unknown;
};
```

De standaardbeperking voor `TMeta`. Vertegenwoordigt een alleen-lezen object met willekeurige properties.

### `ErrorOptions` [#error-options]

```ts
type ErrorOptions =
  ConstructorParameters<typeof Error> extends [
    message?: unknown,
    options?: (infer TOptions) | undefined,
  ]
    ? TOptions
    : { readonly cause?: unknown };
```

Een type afgeleid van het tweede argument van de `Error`-constructor van de runtime. Je kunt er opties met `cause` in doorgeven. De tweede tak is een fallback voor oudere omgevingen.

### `MessageFactory<TMeta>` [#message-factory]

```ts
interface MessageFactory<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> {
  (meta: TMeta): string;
}
```

Een functie die uit `meta` een bericht genereert. Kan zowel voor het standaardbericht van de constructor als voor de geregistreerde waarde van `setErrorMessage` worden gebruikt.

### `I18nErrorBaseParams<TMeta>` [#i18n-error-base-params]

Een type dat de overloads van constructorargumenten vertegenwoordigt.

```ts
type I18nErrorBaseParams<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> =
  [TMeta] extends [undefined]
    ?
        | [message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
        | [meta: undefined, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
    : [meta: TMeta, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined];
```

Alleen wanneer `TMeta` `undefined` is, is de verkorte vorm zonder `meta` toegestaan.

### `I18nErrorBaseConstructor` [#i18n-error-base-constructor]

```ts
interface I18nErrorBaseConstructor {
  new (...args: any): I18nErrorBase;
}
```

Het type van het eerste argument van `setErrorMessage`. Via een intern symbool voor identificatie wordt op typeniveau voorkomen dat klassen die `I18nErrorBase` niet overerven worden binnengesmokkeld.

## Aanvullingen [#notes]

- De standaardwaarde van `lang` voor het oplossen van `message` is `"en"`. Schakel expliciet met `setGlobalConfig({ lang })`
- Er is geen normalisatie van taalcodes of fallbackketen (bijv. uitwijken van `en-US` naar `en`). Niet-geregistreerde talen krijgen uniform het standaardbericht
- Registratiegegevens worden bewaard in een `WeakMap` voor het hele proces. Als je ze in tests wilt isoleren, kun je ze met `globalThis.i18n_error_base__message_map = undefined` weggooien
