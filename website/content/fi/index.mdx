`Error`-luokan periyttämiseen tarkoitettu perusluokka, joka vaihtaa `message`-arvoa dynaamisesti Valibotin globaalin kieliasetuksen (`lang`) mukaisesti.

```ts
import { setGlobalConfig } from "valibot";
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";

class NotFoundError extends I18nErrorBase<{ resource: string }> {}

setErrorMessage(NotFoundError, ({ resource }) => `リソースが見つかりません: ${resource}`, "ja");
setErrorMessage(NotFoundError, ({ resource }) => `Resource not found: ${resource}`, "en");

const error = new NotFoundError({ resource: "user" }, "fallback message");

setGlobalConfig({ lang: "ja" });
console.log(error.message); // リソースが見つかりません: user

setGlobalConfig({ lang: "en" });
console.log(error.message); // Resource not found: user
```

Koska senhetkinen `lang` tarkistetaan aina `message`-ominaisuutta käytettäessä, kielen voi vaihtaa ilman uusien instanssien luomista. Kielille, joille viestiä ei ole rekisteröity, käytetään rakentajalle annettua oletusviestiä.

## Ominaisuudet [#features]

- Ratkaisee `message`-arvon dynaamisesti Valibotin `getGlobalConfig()` / `setGlobalConfig({ lang })` -asetuksen mukaisesti
- Kielikohtaiset viestit rekisteröidään jälkikäteen `setErrorMessage`-funktiolla. Voit rekisteröidä myös `meta`-arvon vastaanottavia funktioita
- Kielille, joille viestiä ei ole rekisteröity, käytetään rakentajan oletusviestiä
- Luokkakohtaisella `static prefix` -ominaisuudella viestin alkuun voidaan lisätä etuliite
- Säilyttää rakentajalle annetun `meta`-arvon ja välittää sen viestin luontifunktioille
- Perii `Error`-luokan, joten `instanceof Error`, `cause` ja `stack` toimivat sellaisenaan
- Viestit tallennetaan `WeakMap`-rakenteeseen, joten tarpeettomat luokat voidaan roskienkerätä

## Miten se toimii [#how-it-works]

`I18nErrorBase`-rakentaja määrittää `message`-ominaisuuden getterinä. Se ratkaistaan jokaisella käyttökerralla seuraavassa järjestyksessä.

1. Hakee arvon `lang` funktiolla `getGlobalConfig()`. Jos sitä ei ole asetettu, arvo on `"en"`
2. Jos `setErrorMessage`-funktiolla rekisteröity `(luokka × lang)` -funktio löytyy, se suoritetaan `meta`-arvolla
3. Muussa tapauksessa palautetaan rakentajalle annettu merkkijono tai funktion tulos (oletusviesti)
4. Jos `static prefix` on asetettu, se liitetään alkuun

:::tip
Oletusviestin funktiomuoto arvioidaan ensimmäisellä käyttökerralla ja tallennetaan sen jälkeen välimuistiin. Rekisteröityjen kielten viestit luodaan `meta`-arvosta uudelleen jokaisella käyttökerralla, joten kielen vaihto näkyy välittömästi.
:::
