## Απαιτήσεις [#requirements]

- Περιβάλλον εκτέλεσης που υποστηρίζει ES modules, όπως το Node.js
- Απαιτείται το `valibot@^1.0.0` ως peer εξάρτηση

Το `message` ακολουθεί τη `lang` του `getGlobalConfig()` του Valibot.

## Εγκατάσταση [#installation]

```package-install
npm i i18n-error-base
```

Αν το Valibot δεν είναι ακόμη εγκατεστημένο, προσθέστε το επίσης.

```package-install
npm i valibot
```

:::warning[Προσοχή στην peer εξάρτηση]
Το `valibot` δεν περιλαμβάνεται. Χωρίς `valibot@^1.0.0` η εισαγωγή αποτυγχάνει.
:::

## Εισαγωγή [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```
