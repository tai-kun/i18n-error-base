Βασική κλάση για επέκταση του `Error` που αλλάζει δυναμικά το `message` σε συγχρονισμό με την καθολική ρύθμιση γλώσσας (`lang`) του Valibot.

```ts
import { setGlobalConfig } from "valibot";
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";

class NotFoundError extends I18nErrorBase<{ resource: string }> {}

setErrorMessage(NotFoundError, ({ resource }) => `リソースが見つかりません: ${resource}`, "ja");
setErrorMessage(NotFoundError, ({ resource }) => `Resource not found: ${resource}`, "en");

const error = new NotFoundError({ resource: "user" }, "fallback message");

setGlobalConfig({ lang: "ja" });
console.log(error.message); // リソースが見つかりません: user

setGlobalConfig({ lang: "en" });
console.log(error.message); // Resource not found: user
```

Καθώς η τρέχουσα `lang` επιλύεται κάθε φορά που προσπελάζεται το `message`, μπορείτε να αλλάζετε γλώσσα χωρίς να δημιουργείτε ξανά στιγμιότυπα. Για γλώσσες χωρίς καταχωρημένο μήνυμα, χρησιμοποιείται το προεπιλεγμένο μήνυμα που δόθηκε στον κατασκευαστή.

## Χαρακτηριστικά [#features]

- Επιλύει το `message` δυναμικά σε συγχρονισμό με τα `getGlobalConfig()` / `setGlobalConfig({ lang })` του Valibot
- Καταχωρεί μηνύματα ανά γλώσσα εκ των υστέρων με το `setErrorMessage`. Μπορείτε επίσης να καταχωρείτε συναρτήσεις που λαμβάνουν `meta`
- Για γλώσσες χωρίς καταχώρηση, χρησιμοποιείται το προεπιλεγμένο μήνυμα του κατασκευαστή
- Προσθέτει πρόθεμα στην αρχή του μηνύματος μέσω `static prefix` ανά κλάση
- Διατηρεί το `meta` στον κατασκευαστή και το διαβιβάζει στις συναρτήσεις δημιουργίας μηνυμάτων
- Κληρονομεί από το `Error`, οπότε τα `instanceof Error`, `cause` και `stack` λειτουργούν κανονικά
- Αποθηκεύει τα μηνύματα σε `WeakMap`, ώστε οι κλάσεις που δεν χρειάζονται πλέον να απορρίπτονται από τον συλλέκτη απορριμμάτων

## Πώς λειτουργεί [#how-it-works]

Ο κατασκευαστής του `I18nErrorBase` ορίζει το `message` ως getter. Επιλύεται με την ακόλουθη σειρά σε κάθε πρόσβαση.

1. Λαμβάνει τη `lang` από το `getGlobalConfig()`. Όταν δεν έχει οριστεί, είναι `"en"`
2. Αν υπάρχει συνάρτηση `(κλάση × lang)` καταχωρημένη με το `setErrorMessage`, την εκτελεί με το `meta`
3. Διαφορετικά, επιστρέφει το προεπιλεγμένο μήνυμα που δόθηκε στον κατασκευαστή (συμβολοσειρά ή αποτέλεσμα συνάρτησης)
4. Αν το `static prefix` έχει οριστεί, το συνδέει στην αρχή

:::tip
Η μορφή συνάρτησης του προεπιλεγμένου μηνύματος αξιολογείται κατά την πρώτη πρόσβαση και αποθηκεύεται προσωρινά στη συνέχεια. Τα μηνύματα για καταχωρημένες γλώσσες αναδημιουργούνται από το `meta` σε κάθε πρόσβαση, οπότε οι αλλαγές γλώσσας ισχύουν άμεσα.
:::
