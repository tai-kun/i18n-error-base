## Krav [#requirements]

- En körningsmiljö som kan hantera ES-moduler, t.ex. Node.js
- `valibot@^1.0.0` krävs som peer-beroende

`message` följer `lang` från Valibots `getGlobalConfig()`.

## Installation [#installation]

```package-install
npm i i18n-error-base
```

Om Valibot inte är installerat ännu lägger du till det också.

```package-install
npm i valibot
```

:::warning[Varning om peer-beroende]
`valibot` buntas inte. Utan `valibot@^1.0.0` kan importen inte lösas.
:::

## Import [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```
