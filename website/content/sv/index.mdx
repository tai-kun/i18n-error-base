En basklass för att ärva `Error` som dynamiskt växlar `message` i takt med Valibots globala språkinställning (`lang`).

```ts
import { setGlobalConfig } from "valibot";
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";

class NotFoundError extends I18nErrorBase<{ resource: string }> {}

setErrorMessage(NotFoundError, ({ resource }) => `リソースが見つかりません: ${resource}`, "ja");
setErrorMessage(NotFoundError, ({ resource }) => `Resource not found: ${resource}`, "en");

const error = new NotFoundError({ resource: "user" }, "fallback message");

setGlobalConfig({ lang: "ja" });
console.log(error.message); // リソースが見つかりません: user

setGlobalConfig({ lang: "en" });
console.log(error.message); // Resource not found: user
```

Eftersom aktuell `lang` slås upp varje gång `message` nås kan du byta språk utan att återskapa instanser. För språk utan registrering faller den tillbaka på standardmeddelandet som skickades till konstruktorn.

## Funktioner [#features]

- Löser `message` dynamiskt i takt med Valibots `getGlobalConfig()` / `setGlobalConfig({ lang })`
- Registrera språkspecifika meddelanden i efterhand med `setErrorMessage`. Du kan också registrera funktioner som tar emot `meta`
- Faller tillbaka på konstruktorns standardmeddelande för språk utan registrering
- Kan lägga till ett prefix i början av meddelandet via klassens `static prefix`
- Behåller `meta` från konstruktorn och skickar den till meddelandefunktioner
- Ärver från `Error`, så `instanceof Error`, `cause` och `stack` fungerar som vanligt
- Lagrar meddelanden i en `WeakMap`, så oanvända klasser kan skräpsamlas

## Så fungerar det [#how-it-works]

`I18nErrorBase`:s konstruktor definierar `message` som en getter. Den löses i följande ordning vid varje åtkomst.

1. Hämtar `lang` från `getGlobalConfig()`. Den är `"en"` när den inte är inställd
2. Om en `(klass × lang)`-funktion registrerad med `setErrorMessage` finns körs den med `meta`
3. Annars returneras standardmeddelandet från konstruktorn (en sträng eller resultatet av en funktion)
4. Om `static prefix` är inställt läggs det till i början

:::tip
Standardmeddelandets funktionsform utvärderas vid första åtkomsten och cachas därefter. Meddelanden för registrerade språk återskapas från `meta` vid varje åtkomst, så språkbyten slår igenom omedelbart.
:::
