## `I18nErrorBase` [#i18n-error-base]

Базов клас за наследяване на `Error`. Предефинира `message` като гетър и го разрешава динамично според `lang` на Valibot.

```ts
import { I18nErrorBase } from "i18n-error-base";

class MyError extends I18nErrorBase<{ code: string }> {}
```

### Типови параметри [#type-params]

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `TMeta` | `ErrorMeta \| undefined` | `ErrorMeta \| undefined` | Типът на допълнителната информация, съхранявана като `meta`. Задайте `undefined`, когато не я използвате. |

### Статични свойства [#static-props]

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `prefix?` | `string` | `undefined` | Когато е зададено, се добавя в началото на разрешеното съобщение. |

### Свойства на инстанцията [#instance-props]

| Prop | Type | Description |
| ---- | ---- | ----------- |
| `meta` | `TMeta` | Допълнителната информация, подадена на конструктора. Достъпна за четене и писане. |
| `message` | `string` | Съобщението, разрешено за текущия `lang`. Изброимо. |
| `cause` | `unknown` | Причината, подадена чрез `ErrorOptions`. Стандартно свойство на `Error`. |

### Конструктор [#constructor]

Когато `TMeta` не включва `undefined`, `meta` е задължително.

```ts
new MyError(meta, message, options?)
```

Когато `TMeta` е `undefined`, `meta` може да се пропусне.

```ts
new MyError(message, options?)
new MyError(meta, message, options?)
```

| Параметър | Тип | Описание |
| ------------ | -- | ---- |
| `meta` | `TMeta` | Допълнителната информация, използвана за генериране на съобщения. |
| `message` | `string \| MessageFactory<TMeta>` | Съобщението по подразбиране, използвано за езици без регистрация. Когато е функция, получава `meta`. |
| `options` | `ErrorOptions` | Опции, съвместими с втория аргумент на `Error` (например `{ cause }`). |

Предаването на не-низова стойност (например число) като `message` я преобразува в низ чрез `String(...)`. Когато фабриката за съобщения върне празен низ, `message` също е празен низ.

### Ред на разрешаване [#resolution-order]

1. Взема `lang` от `getGlobalConfig()` (когато не е зададен, е `"en"`)
2. Изпълнява функцията, регистрирана чрез `setErrorMessage` за този клас и език, с `meta`
3. Когато няма регистрация, използва съобщението по подразбиране от конструктора (низ или оценения резултат от функция; кешира се след първото оценяване)
4. Ако е зададен `static prefix`, го добавя в началото

:::note
Регистрациите се съпоставят по строго равенство на `this.constructor`. Регистрациите за родителски клас не се наследяват от дъщерни класове. Регистрирайте всеки клас, от който се нуждаете.
:::

## `setErrorMessage` [#set-error-message]

Регистрира функция за създаване на съобщения за всеки език.

```ts
import { setErrorMessage } from "i18n-error-base";

setErrorMessage(MyError, (meta) => `...: ${meta.code}`, "ja");
```

| Параметър | Тип | Описание |
| ------------ | -- | ---- |
| `reference` | `I18nErrorBaseConstructor` | Клас, наследяващ `I18nErrorBase`. Класовете, които не го наследяват, са типова грешка. |
| `message` | `string \| (meta) => string` | Съобщението за регистриране. Типът на `meta` се извежда от `meta` на целевия клас. |
| `lang` | `string \| Iterable<string>` | Целевият език. Единичен код или итерируем обект от кодове (например масив). |

Низовете се преобразуват вътрешно във функции, преди да се съхранят. Повторното регистриране на същия клас и език презаписва предишния запис. Данните се съхраняват в `WeakMap` на `globalThis.i18n_error_base__message_map`, с ключ клас и стойности — `Map` от езици към функции.

## Типове [#types]

### `ErrorMeta` [#error-meta]

```ts
type ErrorMeta = {
  readonly [prop: string]: unknown;
};
```

Ограничението по подразбиране за `TMeta`. Представлява обект само за четене с произволни свойства.

### `ErrorOptions` [#error-options]

```ts
type ErrorOptions =
  ConstructorParameters<typeof Error> extends [
    message?: unknown,
    options?: (infer TOptions) | undefined,
  ]
    ? TOptions
    : { readonly cause?: unknown };
```

Тип, изведен от втория аргумент на конструктора `Error` на средата за изпълнение. Можете да подавате опции, включващи `cause`. Вторият клон е резервен вариант за по-стари среди.

### `MessageFactory<TMeta>` [#message-factory]

```ts
interface MessageFactory<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> {
  (meta: TMeta): string;
}
```

Функция, която генерира съобщение от `meta`. Използва се както за съобщението по подразбиране на конструктора, така и за стойностите, регистрирани с `setErrorMessage`.

### `I18nErrorBaseParams<TMeta>` [#i18n-error-base-params]

Тип, представляващ претоварванията на аргументите на конструктора.

```ts
type I18nErrorBaseParams<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> =
  [TMeta] extends [undefined]
    ?
        | [message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
        | [meta: undefined, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
    : [meta: TMeta, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined];
```

Формата без `meta` е разрешена само когато `TMeta` е `undefined`.

### `I18nErrorBaseConstructor` [#i18n-error-base-constructor]

```ts
interface I18nErrorBaseConstructor {
  new (...args: any): I18nErrorBase;
}
```

Типът на първия аргумент на `setErrorMessage`. Вътрешен идентифициращ символ предотвратява на типово ниво промъкването на класове, които не наследяват `I18nErrorBase`.

## Забележки [#notes]

- `lang` по подразбиране, използван за разрешаване на `message`, е `"en"`. Превключете го изрично с `setGlobalConfig({ lang })`
- Няма нормализация на езиковите кодове и няма верига за резервен вариант (напр. връщане от `en-US` към `en`). Нерегистрираните езици винаги дават съобщението по подразбиране
- Данните за регистрация се съхраняват в `WeakMap` за целия процес. За да ги изолирате в тестове, ги изтрийте с `globalThis.i18n_error_base__message_map = undefined`
