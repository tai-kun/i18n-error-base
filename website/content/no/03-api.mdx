## `I18nErrorBase` [#i18n-error-base]

En baseklasse for å utvide `Error`. Den omdefinerer `message` som en getter og løser den dynamisk basert på Valibots `lang`.

```ts
import { I18nErrorBase } from "i18n-error-base";

class MyError extends I18nErrorBase<{ code: string }> {}
```

### Typeparametre [#type-params]

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `TMeta` | `ErrorMeta \| undefined` | `ErrorMeta \| undefined` | Typen for tilleggsinformasjonen som beholdes som `meta`. Angi `undefined` når den ikke brukes. |

### Statiske egenskaper [#static-props]

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `prefix?` | `string` | `undefined` | Når den er satt, legges den til foran den løste meldingen. |

### Instansegenskaper [#instance-props]

| Prop | Type | Description |
| ---- | ---- | ----------- |
| `meta` | `TMeta` | Tilleggsinformasjonen som ble sendt til konstruktøren. Kan både leses og skrives. |
| `message` | `string` | Meldingen løst for gjeldende `lang`. Enumerable. |
| `cause` | `unknown` | Årsaken sendt via `ErrorOptions`. En standard `Error`-egenskap. |

### Konstruktør [#constructor]

Når `TMeta` ikke omfatter `undefined`, er `meta` påkrevd.

```ts
new MyError(meta, message, options?)
```

Når `TMeta` er `undefined`, kan `meta` utelates.

```ts
new MyError(message, options?)
new MyError(meta, message, options?)
```

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `meta` | `TMeta` | Tilleggsinformasjonen som brukes til meldingsgenerering. |
| `message` | `string \| MessageFactory<TMeta>` | Standardmeldingen som brukes for språk uten registrering. Når det er en funksjon, mottar den `meta`. |
| `options` | `ErrorOptions` | Alternativer som er kompatible med det andre argumentet til `Error` (for eksempel `{ cause }`). |

Hvis en ikke-strengverdi (for eksempel et tall) sendes som `message`, konverteres den til en streng med `String(...)`. Hvis en meldingsfunksjon returnerer en tom streng, er `message` også en tom streng.

### Løsningsrekkefølge [#resolution-order]

1. Hent `lang` fra `getGlobalConfig()` (`"en"` når den ikke er satt)
2. Kjør funksjonen registrert med `setErrorMessage` for den aktuelle klassen og det aktuelle språket med `meta`
3. Hvis uregistrert, bruk konstruktørens standardmelding (en streng eller det evaluerte resultatet av en funksjon; bufres etter første evaluering)
4. Hvis `static prefix` er satt, legg det til foran

:::note
Registreringer matches ved streng likhet på `this.constructor`. Registreringer på en foreldreklasse arves ikke av underklasser. Registrer hver klasse du trenger.
:::

## `setErrorMessage` [#set-error-message]

Registrerer en meldingsfunksjon per språk.

```ts
import { setErrorMessage } from "i18n-error-base";

setErrorMessage(MyError, (meta) => `...: ${meta.code}`, "ja");
```

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `reference` | `I18nErrorBaseConstructor` | En klasse som arver fra `I18nErrorBase`. Klasser som ikke arver fra den, er en typefeil. |
| `message` | `string \| (meta) => string` | Meldingen som skal registreres. Typen til `meta` utledes fra målklassens `meta`. |
| `lang` | `string \| Iterable<string>` | Målspråket. En enkelt kode eller et itererbart objekt med koder (for eksempel en matrise). |

Strenger konverteres til funksjoner internt før de lagres. Å registrere samme klasse og språk på nytt overskriver den forrige oppføringen. Data lagres i `WeakMap` på `globalThis.i18n_error_base__message_map`, nøklet på klasse med verdier som mapper språk til funksjoner.

## Typer [#types]

### `ErrorMeta` [#error-meta]

```ts
type ErrorMeta = {
  readonly [prop: string]: unknown;
};
```

Standardbegrensningen for `TMeta`. Representerer et skrivebeskyttet objekt med vilkårlige egenskaper.

### `ErrorOptions` [#error-options]

```ts
type ErrorOptions =
  ConstructorParameters<typeof Error> extends [
    message?: unknown,
    options?: (infer TOptions) | undefined,
  ]
    ? TOptions
    : { readonly cause?: unknown };
```

En type avledet fra det andre argumentet til kjøremiljøets `Error`-konstruktør. Du kan sende alternativer inkludert `cause`. Den sistnevnte grenen er en fallback for eldre miljøer.

### `MessageFactory<TMeta>` [#message-factory]

```ts
interface MessageFactory<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> {
  (meta: TMeta): string;
}
```

En funksjon som genererer en melding fra `meta`. Brukes både for konstruktørens standardmelding og for verdier registrert med `setErrorMessage`.

### `I18nErrorBaseParams<TMeta>` [#i18n-error-base-params]

En type som representerer overbelastningene av konstruktørargumenter.

```ts
type I18nErrorBaseParams<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> =
  [TMeta] extends [undefined]
    ?
        | [message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
        | [meta: undefined, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
    : [meta: TMeta, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined];
```

Formen uten `meta` er bare tillatt når `TMeta` er `undefined`.

### `I18nErrorBaseConstructor` [#i18n-error-base-constructor]

```ts
interface I18nErrorBaseConstructor {
  new (...args: any): I18nErrorBase;
}
```

Typen til det første argumentet til `setErrorMessage`. Et internt identifiseringssymbol hindrer klasser som ikke arver fra `I18nErrorBase` i å slippe inn på typenivå.

## Merknader [#notes]

- Standard-`lang` som brukes til å løse `message`, er `"en"`. Bytt den eksplisitt med `setGlobalConfig({ lang })`
- Det finnes ingen normalisering av språkkoder og ingen fallback-kjede (f.eks. fallback fra `en-US` til `en`). Uregistrerte språk gir alltid standardmeldingen
- Registreringsdata beholdes i en prosessomfattende `WeakMap`. For å isolere tester kan du forkaste den med `globalThis.i18n_error_base__message_map = undefined`
