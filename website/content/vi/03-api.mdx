## `I18nErrorBase` [#i18n-error-base]

Là lớp cơ sở để kế thừa `Error`. Định nghĩa lại `message` dưới dạng getter và giải quyết động theo `lang` của Valibot.

```ts
import { I18nErrorBase } from "i18n-error-base";

class MyError extends I18nErrorBase<{ code: string }> {}
```

### Tham số type [#type-params]

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `TMeta` | `ErrorMeta \| undefined` | `ErrorMeta \| undefined` | Kiểu thông tin bổ sung được giữ dưới dạng `meta`. Nếu không dùng, chỉ định `undefined`. |

### Thuộc tính static [#static-props]

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `prefix?` | `string` | `undefined` | Nếu thiết lập, sẽ nối vào đầu thông báo đã giải quyết. |

### Thuộc tính instance [#instance-props]

| Prop | Type | Description |
| ---- | ---- | ----------- |
| `meta` | `TMeta` | Thông tin bổ sung đã truyền vào constructor. Có thể đọc/ghi. |
| `message` | `string` | Thông báo được giải quyết theo `lang` hiện tại. Có thể liệt kê được. |
| `cause` | `unknown` | Nguyên nhân đã truyền bằng `ErrorOptions`. Là thuộc tính chuẩn của `Error`. |

### Constructor [#constructor]

Nếu `TMeta` không bao gồm `undefined`, `meta` là bắt buộc.

```ts
new MyError(meta, message, options?)
```

Nếu `TMeta` là `undefined`, bạn có thể bỏ qua `meta`.

```ts
new MyError(message, options?)
new MyError(meta, message, options?)
```

| Tham số | Kiểu | Mô tả |
| ------------ | -- | ---- |
| `meta` | `TMeta` | Thông tin bổ sung dùng để tạo thông báo. |
| `message` | `string \| MessageFactory<TMeta>` | Thông báo mặc định dùng cho ngôn ngữ chưa đăng ký. Nếu là hàm, nó nhận `meta`. |
| `options` | `ErrorOptions` | Option tương thích với tham số thứ 2 của `Error` (`{ cause }` v.v.). |

Nếu truyền giá trị không phải chuỗi (như số) cho `message`, nó sẽ được chuyển thành chuỗi bằng `String(...)`. Nếu message factory trả về chuỗi rỗng, `message` cũng sẽ là chuỗi rỗng.

### Thứ tự giải quyết [#resolution-order]

1. Lấy `lang` của `getGlobalConfig()` (khi chưa thiết lập là `"en"`)
2. Thực thi hàm của class và ngôn ngữ đó đã đăng ký bằng `setErrorMessage` kèm `meta`
3. Nếu chưa đăng ký, dùng thông báo mặc định của constructor (chuỗi hoặc kết quả đánh giá hàm. Cache sau lần đánh giá đầu tiên)
4. Nếu có `static prefix`, nối nó vào đầu thông báo

:::note
Việc khớp đăng ký là so khớp chính xác `this.constructor`. Đăng ký ở class cha sẽ không được kế thừa bởi class con. Hãy đăng ký cho từng class cần thiết.
:::

## `setErrorMessage` [#set-error-message]

Đăng ký hàm tạo thông báo theo từng ngôn ngữ.

```ts
import { setErrorMessage } from "i18n-error-base";

setErrorMessage(MyError, (meta) => `...: ${meta.code}`, "ja");
```

| Tham số | Kiểu | Mô tả |
| ------------ | -- | ---- |
| `reference` | `I18nErrorBaseConstructor` | Class kế thừa `I18nErrorBase`. Class không kế thừa sẽ gây lỗi type. |
| `message` | `string \| (meta) => string` | Thông báo cần đăng ký. Kiểu của `meta` được suy luận từ `meta` của class đích. |
| `lang` | `string \| Iterable<string>` | Ngôn ngữ đích. Một mã đơn hoặc đối tượng iterable của các mã (như mảng). |

Chuỗi được chuyển thành hàm và lưu trữ bên trong. Đăng ký lại cùng class và ngôn ngữ sẽ ghi đè. Nơi lưu là `WeakMap` của `globalThis.i18n_error_base__message_map`, với key là class và value là `Map` từ ngôn ngữ tới hàm.

## Type [#types]

### `ErrorMeta` [#error-meta]

```ts
type ErrorMeta = {
  readonly [prop: string]: unknown;
};
```

Là ràng buộc mặc định của `TMeta`. Biểu thị đối tượng chỉ đọc có thuộc tính tùy ý.

### `ErrorOptions` [#error-options]

```ts
type ErrorOptions =
  ConstructorParameters<typeof Error> extends [
    message?: unknown,
    options?: (infer TOptions) | undefined,
  ]
    ? TOptions
    : { readonly cause?: unknown };
```

Là type suy ra từ tham số thứ 2 của constructor `Error` trong môi trường thực thi. Có thể truyền option bao gồm `cause`. Nhánh sau là fallback cho môi trường cũ.

### `MessageFactory<TMeta>` [#message-factory]

```ts
interface MessageFactory<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> {
  (meta: TMeta): string;
}
```

Là hàm tạo thông báo từ `meta`. Có thể dùng cho cả thông báo mặc định của constructor và giá trị đăng ký của `setErrorMessage`.

### `I18nErrorBaseParams<TMeta>` [#i18n-error-base-params]

Là type biểu thị overload của tham số constructor.

```ts
type I18nErrorBaseParams<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> =
  [TMeta] extends [undefined]
    ?
        | [message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
        | [meta: undefined, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
    : [meta: TMeta, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined];
```

Chỉ khi `TMeta` là `undefined`, dạng rút gọn bỏ qua `meta` mới được cho phép.

### `I18nErrorBaseConstructor` [#i18n-error-base-constructor]

```ts
interface I18nErrorBaseConstructor {
  new (...args: any): I18nErrorBase;
}
```

Là type của tham số thứ nhất của `setErrorMessage`. Nhờ symbol nhận dạng nội bộ, việc lẫn class không kế thừa `I18nErrorBase` bị ngăn ở cấp độ type.

## Ghi chú bổ sung [#notes]

- Giá trị mặc định của `lang` dùng để giải quyết `message` là `"en"`. Hãy chuyển rõ ràng bằng `setGlobalConfig({ lang })`
- Không có chuẩn hóa mã ngôn ngữ hay chuỗi fallback (ví dụ: từ `en-US` về `en`). Ngôn ngữ chưa đăng ký đều thành thông báo mặc định
- Dữ liệu đăng ký được giữ trong `WeakMap` toàn cục của process. Nếu muốn cô lập trong test, có thể hủy bằng `globalThis.i18n_error_base__message_map = undefined`
