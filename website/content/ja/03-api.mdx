## `I18nErrorBase`

`Error` を継承するための基底クラスです。`message` をゲッターとして再定義し、Valibot の `lang` に応じて動的に解決します。

```ts
import { I18nErrorBase } from "i18n-error-base";

class MyError extends I18nErrorBase<{ code: string }> {}
```

### 型パラメーター

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `TMeta` | `ErrorMeta \| undefined` | `ErrorMeta \| undefined` | `meta` として保持する付随情報の型。使わない場合は `undefined` を指定します。 |

### 静的プロパティー

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `prefix?` | `string` | `undefined` | 設定すると解決後のメッセージ先頭に連結されます。 |

### インスタンスプロパティー

| Prop | Type | Description |
| ---- | ---- | ----------- |
| `meta` | `TMeta` | コンストラクターで渡した付随情報。読み書き可能です。 |
| `message` | `string` | 現在の `lang` に応じて解決されるメッセージ。列挙可能です。 |
| `cause` | `unknown` | `ErrorOptions` で渡した原因。`Error` の標準プロパティーです。 |

### コンストラクター

`TMeta` が `undefined` を含まない場合、`meta` は必須です。

```ts
new MyError(meta, message, options?)
```

`TMeta` が `undefined` の場合、`meta` を省略できます。

```ts
new MyError(message, options?)
new MyError(meta, message, options?)
```

| パラメーター | 型 | 説明 |
| ------------ | -- | ---- |
| `meta` | `TMeta` | メッセージ生成に使う付随情報。 |
| `message` | `string \| MessageFactory<TMeta>` | 登録のない言語で使う既定メッセージ。関数の場合は `meta` を受け取ります。 |
| `options` | `ErrorOptions` | `Error` の第 2 引数と互換のオプション（`{ cause }` など）。 |

`message` に文字列以外（数値など）を渡した場合は `String(...)` で文字列化されます。メッセージファクトリーが空文字を返した場合は `message` も空文字になります。

### 解決順序

1. `getGlobalConfig()` の `lang` を取得します（未設定時は `"en"`）
2. `setErrorMessage` で登録された当該クラス・当該言語の関数を `meta` 付きで実行します
3. 未登録ならコンストラクターの既定メッセージ（文字列または関数の評価結果。初回評価後はキャッシュ）を使います
4. `static prefix` があれば先頭に連結します

:::note
登録の照合は `this.constructor` の完全一致です。親クラスへの登録は子クラスに継承されません。必要なクラスごとに登録してください。
:::

## `setErrorMessage`

言語ごとのメッセージ作成関数を登録します。

```ts
import { setErrorMessage } from "i18n-error-base";

setErrorMessage(MyError, (meta) => `...: ${meta.code}`, "ja");
```

| パラメーター | 型 | 説明 |
| ------------ | -- | ---- |
| `reference` | `I18nErrorBaseConstructor` | `I18nErrorBase` を継承したクラス。継承していないクラスは型エラーになります。 |
| `message` | `string \| (meta) => string` | 登録するメッセージ。`meta` の型は対象クラスの `meta` から推論されます。 |
| `lang` | `string \| Iterable<string>` | 対象言語。単一コードまたはコードの反復可能オブジェクト（配列など）。 |

文字列は内部で関数に変換して保持されます。同じクラス・同じ言語への再登録は上書きです。保存先は `globalThis.i18n_error_base__message_map` の `WeakMap` で、キーはクラス、値は言語から関数への `Map` です。

## 型

### `ErrorMeta`

```ts
type ErrorMeta = {
  readonly [prop: string]: unknown;
};
```

`TMeta` の既定の制約です。任意のプロパティーを持つ読み取り専用オブジェクトを表します。

### `ErrorOptions`

```ts
type ErrorOptions =
  ConstructorParameters<typeof Error> extends [
    message?: unknown,
    options?: (infer TOptions) | undefined,
  ]
    ? TOptions
    : { readonly cause?: unknown };
```

実行環境の `Error` コンストラクター第 2 引数から導出した型です。`cause` を含むオプションを渡せます。後者の分岐は古い環境向けのフォールバックです。

### `MessageFactory<TMeta>`

```ts
interface MessageFactory<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> {
  (meta: TMeta): string;
}
```

`meta` からメッセージを生成する関数です。コンストラクターの既定メッセージと `setErrorMessage` の登録値の両方で使えます。

### `I18nErrorBaseParams<TMeta>`

コンストラクター引数のオーバーロードを表す型です。

```ts
type I18nErrorBaseParams<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> =
  [TMeta] extends [undefined]
    ?
        | [message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
        | [meta: undefined, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
    : [meta: TMeta, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined];
```

`TMeta` が `undefined` の場合のみ `meta` の省略形が許可されます。

### `I18nErrorBaseConstructor`

```ts
interface I18nErrorBaseConstructor {
  new (...args: any): I18nErrorBase;
}
```

`setErrorMessage` の第 1 引数の型です。内部識別用のシンボルにより、`I18nErrorBase` を継承しないクラスの混入を型レベルで防ぎます。

## 補足

- `message` の解決に使う `lang` の既定値は `"en"` です。`setGlobalConfig({ lang })` で明示的に切り替えてください
- 言語コードの正規化やフォールバックチェーン（例: `en-US` から `en` への退避）はありません。未登録言語は一律で既定メッセージになります
- 登録データはプロセス全体の `WeakMap` に保持されます。テストで隔離したい場合は `globalThis.i18n_error_base__message_map = undefined` で破棄できます
