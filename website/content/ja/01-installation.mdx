## 要件 [#requirements]

- Node.js など ES モジュールを扱える実行環境です。
- ピア依存として `valibot@^1.0.0` が必要です。

`message` は  Valibot の `getGlobalConfig()` の `lang` に従います。

## インストール [#installation]

```package-install
npm i i18n-error-base
```

Valibot が未導入の場合はあわせて追加してください。

```package-install
npm i valibot
```

:::warning[ピア依存に注意]
`valibot` はバンドルしません。`valibot@^1.0.0` がないとインポートで解決エラーになります。
:::

## インポート [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```
