## 要件 [#requirements]

- Node.js など ES モジュールを扱える実行環境
- ピア依存として `valibot@^1.0.0` が必要です

`I18nErrorBase` は内部で Valibot の `getGlobalConfig()` を参照し、現在の `lang` を取得します。Valibot を使っていないプロジェクトでも、言語切り替えのためだけに `setGlobalConfig({ lang })` を呼び出せば動作します。

## インストール [#installation]

```package-install
npm i i18n-error-base
```

Valibot が未導入の場合はあわせて追加してください。

```package-install
npm i valibot
```

:::warning[ピア依存に注意]
`i18n-error-base` は `valibot` をバンドルしません。ホスト側で `valibot@^1.0.0` を用意しないと、インポート時に解決エラーになります。
:::

## インポート [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```

既定のエクスポートも用意されています。

```ts
import I18nErrorBase from "i18n-error-base";
import setErrorMessage from "i18n-error-base";
```

:::note
パッケージは ESM（`"type": "module"`）で配布され、副作用はありません（`"sideEffects": false`）。型定義は `dist/src/*.d.ts` から解決されます。
:::
