Základní třída pro dědění z `Error`, která dynamicky přepíná `message` podle globálního nastavení jazyka (`lang`) Valibotu.

```ts
import { setGlobalConfig } from "valibot";
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";

class NotFoundError extends I18nErrorBase<{ resource: string }> {}

setErrorMessage(NotFoundError, ({ resource }) => `リソースが見つかりません: ${resource}`, "ja");
setErrorMessage(NotFoundError, ({ resource }) => `Resource not found: ${resource}`, "en");

const error = new NotFoundError({ resource: "user" }, "fallback message");

setGlobalConfig({ lang: "ja" });
console.log(error.message); // リソースが見つかりません: user

setGlobalConfig({ lang: "en" });
console.log(error.message); // Resource not found: user
```

Protože se aktuální `lang` resolvuje při každém přístupu k `message`, lze jazyk přepnout bez opětovného vytváření instancí. Pro jazyky bez registrace se použije výchozí zpráva předaná konstruktoru.

## Funkce [#features]

- Dynamicky resolvuje `message` v souladu s `getGlobalConfig()` / `setGlobalConfig({ lang })` Valibotu
- Zprávy pro jednotlivé jazyky se dodatečně registrují pomocí `setErrorMessage`. Lze registrovat i funkce přijímající `meta`
- Pro jazyky bez registrace se použije výchozí zpráva z konstruktoru
- Pomocí `static prefix` na úrovni třídy lze na začátek zprávy přidat předponu
- `meta` se uchovává v konstruktoru a předává se funkcím generujícím zprávy
- Protože dědí z `Error`, `instanceof Error`, `cause` i `stack` fungují beze změny
- Zprávy se ukládají do `WeakMap`, takže nepotřebné třídy mohou být uvolněny garbage collectorem

## Jak to funguje [#how-it-works]

Konstruktor `I18nErrorBase` definuje `message` jako getter. Při každém přístupu se vyhodnocuje v následujícím pořadí.

1. Získá `lang` z `getGlobalConfig()`. Není-li nastaveno, je to `"en"`
2. Pokud existuje funkce `(třída × lang)` registrovaná pomocí `setErrorMessage`, spustí ji s `meta`
3. Jinak vrátí výchozí zprávu předanou konstruktoru (řetězec nebo výsledek funkce)
4. Je-li nastaven `static prefix`, připojí jej na začátek

:::tip
Funkční forma výchozí zprávy se vyhodnotí při prvním přístupu a poté se ukládá do mezipaměti. Zprávy registrovaných jazyků se při každém přístupu znovu generují z `meta`, takže přepnutí jazyka se projeví okamžitě.
:::
