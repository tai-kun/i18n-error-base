## `I18nErrorBase` [#i18n-error-base]

Základní třída pro dědění z `Error`. Znovu definuje `message` jako getter a dynamicky jej resolvuje podle `lang` Valibotu.

```ts
import { I18nErrorBase } from "i18n-error-base";

class MyError extends I18nErrorBase<{ code: string }> {}
```

### Parametry typu [#type-params]

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `TMeta` | `ErrorMeta \| undefined` | `ErrorMeta \| undefined` | Typ doprovodných informací uchovávaných jako `meta`. Pokud se nepoužívají, zadejte `undefined`. |

### Statické vlastnosti [#static-props]

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `prefix?` | `string` | `undefined` | Je-li nastaven, připojí se na začátek vyhodnocené zprávy. |

### Vlastnosti instance [#instance-props]

| Prop | Type | Description |
| ---- | ---- | ----------- |
| `meta` | `TMeta` | Doprovodné informace předané konstruktoru. Lze číst i zapisovat. |
| `message` | `string` | Zpráva vyhodnocená podle aktuálního `lang`. Je enumerovatelná. |
| `cause` | `unknown` | Příčina předaná přes `ErrorOptions`. Standardní vlastnost `Error`. |

### Konstruktor [#constructor]

Pokud `TMeta` nezahrnuje `undefined`, je `meta` povinné.

```ts
new MyError(meta, message, options?)
```

Pokud je `TMeta` typu `undefined`, lze `meta` vynechat.

```ts
new MyError(message, options?)
new MyError(meta, message, options?)
```

| Parametr | Typ | Popis |
| -------- | --- | ----- |
| `meta` | `TMeta` | Doprovodné informace používané ke generování zprávy. |
| `message` | `string \| MessageFactory<TMeta>` | Výchozí zpráva pro jazyky bez registrace. Je-li funkcí, přijímá `meta`. |
| `options` | `ErrorOptions` | Volby kompatibilní s druhým argumentem `Error` (např. `{ cause }`). |

Pokud se do `message` předá jiná než řetězcová hodnota (např. číslo), převede se pomocí `String(...)` na řetězec. Vrátí-li továrna zpráv prázdný řetězec, bude i `message` prázdným řetězcem.

### Pořadí vyhodnocení [#resolution-order]

1. Získá `lang` z `getGlobalConfig()` (není-li nastaveno, `"en"`)
2. Spustí funkci pro danou třídu a jazyk registrovanou pomocí `setErrorMessage` s `meta`
3. Není-li registrována, použije výchozí zprávu z konstruktoru (řetězec nebo výsledek vyhodnocení funkce; po prvním vyhodnocení se ukládá do mezipaměti)
4. Je-li `static prefix`, připojí jej na začátek

:::note
Shoda registrace je striktní rovnost `this.constructor`. Registrace pro rodičovskou třídu se na potomky nedědí. Registrujte pro každou potřebnou třídu zvlášť.
:::

## `setErrorMessage` [#set-error-message]

Registruje funkci pro tvorbu zprávy pro jednotlivé jazyky.

```ts
import { setErrorMessage } from "i18n-error-base";

setErrorMessage(MyError, (meta) => `...: ${meta.code}`, "ja");
```

| Parametr | Typ | Popis |
| -------- | --- | ----- |
| `reference` | `I18nErrorBaseConstructor` | Třída dědící z `I18nErrorBase`. Třídy, které nedědí, způsobí typovou chybu. |
| `message` | `string \| (meta) => string` | Zpráva k registraci. Typ `meta` se odvodí z `meta` cílové třídy. |
| `lang` | `string \| Iterable<string>` | Cílový jazyk. Jednotlivý kód nebo iterovatelný objekt kódů (např. pole). |

Řetězec se interně převede na funkci a uloží. Opětovná registrace stejné třídy a jazyka původní hodnotu přepíše. Úložištěm je `WeakMap` v `globalThis.i18n_error_base__message_map`, kde klíčem je třída a hodnotou `Map` od jazyka k funkci.

## Typy [#types]

### `ErrorMeta` [#error-meta]

```ts
type ErrorMeta = {
  readonly [prop: string]: unknown;
};
```

Výchozí omezení pro `TMeta`. Představuje objekt jen pro čtení s libovolnými vlastnostmi.

### `ErrorOptions` [#error-options]

```ts
type ErrorOptions =
  ConstructorParameters<typeof Error> extends [
    message?: unknown,
    options?: (infer TOptions) | undefined,
  ]
    ? TOptions
    : { readonly cause?: unknown };
```

Typ odvozený z druhého argumentu konstruktoru `Error` v daném běhovém prostředí. Lze předat volby obsahující `cause`. Druhá větev je fallback pro starší prostředí.

### `MessageFactory<TMeta>` [#message-factory]

```ts
interface MessageFactory<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> {
  (meta: TMeta): string;
}
```

Funkce generující zprávu z `meta`. Lze ji použít jak pro výchozí zprávu konstruktoru, tak pro registrovanou hodnotu `setErrorMessage`.

### `I18nErrorBaseParams<TMeta>` [#i18n-error-base-params]

Typ představující přetížení argumentů konstruktoru.

```ts
type I18nErrorBaseParams<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> =
  [TMeta] extends [undefined]
    ?
        | [message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
        | [meta: undefined, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
    : [meta: TMeta, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined];
```

Pouze pokud je `TMeta` typu `undefined`, je povolena zkrácená forma bez `meta`.

### `I18nErrorBaseConstructor` [#i18n-error-base-constructor]

```ts
interface I18nErrorBaseConstructor {
  new (...args: any): I18nErrorBase;
}
```

Typ prvního argumentu `setErrorMessage`. Vnitřní symbol brání na typové úrovni příměsi tříd, které nedědí z `I18nErrorBase`.

## Poznámky [#notes]

- Výchozí hodnota `lang` používaná k vyhodnocení `message` je `"en"`. Explicitně přepínejte pomocí `setGlobalConfig({ lang })`
- Kódy jazyků se nenormalizují ani neexistuje fallback řetězec (např. ústup z `en-US` na `en`). Neregistrované jazyky vždy použijí výchozí zprávu
- Registrační data se uchovávají v `WeakMap` celého procesu. Chcete-li je v testech izolovat, můžete je zahodit pomocí `globalThis.i18n_error_base__message_map = undefined`
