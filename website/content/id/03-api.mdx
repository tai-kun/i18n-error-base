## `I18nErrorBase` [#i18n-error-base]

Kelas dasar untuk mewarisi `Error`. Mendefinisikan ulang `message` sebagai getter dan menyelesaikannya secara dinamis berdasarkan `lang` Valibot.

```ts
import { I18nErrorBase } from "i18n-error-base";

class MyError extends I18nErrorBase<{ code: string }> {}
```

### Parameter tipe [#type-params]

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `TMeta` | `ErrorMeta \| undefined` | `ErrorMeta \| undefined` | Tipe informasi tambahan yang disimpan sebagai `meta`. Tentukan `undefined` jika tidak digunakan. |

### Properti statis [#static-props]

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `prefix?` | `string` | `undefined` | Jika diatur, digabungkan di awal pesan yang telah diselesaikan. |

### Properti instans [#instance-props]

| Prop | Type | Description |
| ---- | ---- | ----------- |
| `meta` | `TMeta` | Informasi tambahan yang diberikan ke konstruktor. Dapat dibaca dan ditulis. |
| `message` | `string` | Pesan yang diselesaikan berdasarkan `lang` saat ini. Dapat dienumerasi. |
| `cause` | `unknown` | Penyebab yang diberikan melalui `ErrorOptions`. Properti standar `Error`. |

### Konstruktor [#constructor]

Jika `TMeta` tidak mencakup `undefined`, `meta` wajib diisi.

```ts
new MyError(meta, message, options?)
```

Jika `TMeta` adalah `undefined`, `meta` dapat dihilangkan.

```ts
new MyError(message, options?)
new MyError(meta, message, options?)
```

| Parameter | Tipe | Deskripsi |
| --------- | ---- | --------- |
| `meta` | `TMeta` | Informasi tambahan yang digunakan untuk pembuatan pesan. |
| `message` | `string \| MessageFactory<TMeta>` | Pesan default yang digunakan untuk bahasa yang tidak terdaftar. Jika berupa fungsi, menerima `meta`. |
| `options` | `ErrorOptions` | Opsi yang kompatibel dengan argumen kedua `Error` (seperti `{ cause }`). |

Jika `message` diberi nilai selain string (misalnya angka), nilainya akan diubah menjadi string dengan `String(...)`. Jika pabrik pesan mengembalikan string kosong, `message` juga menjadi string kosong.

### Urutan resolusi [#resolution-order]

1. Mendapatkan `lang` dari `getGlobalConfig()` ( `"en"` jika belum diatur)
2. Menjalankan fungsi untuk kelas dan bahasa tersebut yang didaftarkan dengan `setErrorMessage` beserta `meta`
3. Jika tidak terdaftar, gunakan pesan default konstruktor (string atau hasil evaluasi fungsi; di-cache setelah evaluasi pertama)
4. Jika `static prefix` ada, gabungkan di awal

:::note
Pencocokan pendaftaran adalah kecocokan persis `this.constructor`. Pendaftaran ke kelas induk tidak diwarisi oleh kelas anak. Daftarkan untuk setiap kelas yang dibutuhkan.
:::

## `setErrorMessage` [#set-error-message]

Mendaftarkan fungsi pembuat pesan tiap bahasa.

```ts
import { setErrorMessage } from "i18n-error-base";

setErrorMessage(MyError, (meta) => `...: ${meta.code}`, "ja");
```

| Parameter | Tipe | Deskripsi |
| --------- | ---- | --------- |
| `reference` | `I18nErrorBaseConstructor` | Kelas yang mewarisi `I18nErrorBase`. Kelas yang tidak mewarisinya akan menjadi error tipe. |
| `message` | `string \| (meta) => string` | Pesan yang didaftarkan. Tipe `meta` disimpulkan dari `meta` kelas target. |
| `lang` | `string \| Iterable<string>` | Bahasa target. Kode tunggal atau objek yang dapat diiterasi berisi kode (seperti array). |

String diubah menjadi fungsi secara internal sebelum disimpan. Pendaftaran ulang untuk kelas dan bahasa yang sama akan menimpa. Tempat penyimpanan adalah `WeakMap` di `globalThis.i18n_error_base__message_map`, dengan kunci berupa kelas dan nilai berupa `Map` dari bahasa ke fungsi.

## Tipe [#types]

### `ErrorMeta` [#error-meta]

```ts
type ErrorMeta = {
  readonly [prop: string]: unknown;
};
```

Batasan default untuk `TMeta`. Menyatakan objek hanya-baca dengan properti sembarang.

### `ErrorOptions` [#error-options]

```ts
type ErrorOptions =
  ConstructorParameters<typeof Error> extends [
    message?: unknown,
    options?: (infer TOptions) | undefined,
  ]
    ? TOptions
    : { readonly cause?: unknown };
```

Tipe yang diturunkan dari argumen kedua konstruktor `Error` lingkungan runtime. Opsi yang memuat `cause` dapat diberikan. Cabang terakhir adalah fallback untuk lingkungan lama.

### `MessageFactory<TMeta>` [#message-factory]

```ts
interface MessageFactory<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> {
  (meta: TMeta): string;
}
```

Fungsi yang menghasilkan pesan dari `meta`. Digunakan baik untuk pesan default konstruktor maupun nilai yang didaftarkan dengan `setErrorMessage`.

### `I18nErrorBaseParams<TMeta>` [#i18n-error-base-params]

Tipe yang menyatakan overload argumen konstruktor.

```ts
type I18nErrorBaseParams<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> =
  [TMeta] extends [undefined]
    ?
        | [message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
        | [meta: undefined, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
    : [meta: TMeta, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined];
```

Bentuk tanpa `meta` hanya diizinkan jika `TMeta` adalah `undefined`.

### `I18nErrorBaseConstructor` [#i18n-error-base-constructor]

```ts
interface I18nErrorBaseConstructor {
  new (...args: any): I18nErrorBase;
}
```

Tipe argumen pertama `setErrorMessage`. Simbol identifikasi internal mencegah tercampurnya kelas yang tidak mewarisi `I18nErrorBase` pada tingkat tipe.

## Catatan [#notes]

- Nilai default `lang` yang digunakan untuk menyelesaikan `message` adalah `"en"`. Beralihlah secara eksplisit dengan `setGlobalConfig({ lang })`
- Tidak ada normalisasi kode bahasa maupun rantai fallback (misalnya pengalihan dari `en-US` ke `en`). Bahasa yang tidak terdaftar selalu menjadi pesan default
- Data pendaftaran disimpan di `WeakMap` seluruh proses. Untuk mengisolasi pengujian, data dapat dibuang dengan `globalThis.i18n_error_base__message_map = undefined`
