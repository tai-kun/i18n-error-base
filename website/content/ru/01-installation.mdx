## Требования [#requirements]

- Среда выполнения, поддерживающая ES-модули, например Node.js
- В качестве peer-зависимости требуется `valibot@^1.0.0`

`I18nErrorBase` внутри обращается к `getGlobalConfig()` из Valibot для получения текущего `lang`. Даже в проектах, которые иначе не используют Valibot, достаточно вызвать `setGlobalConfig({ lang })` только ради переключения языка.

## Установка [#installation]

```package-install
npm i i18n-error-base
```

Если Valibot ещё не установлен, добавьте и его.

```package-install
npm i valibot
```

:::warning[Внимание: peer-зависимость]
`i18n-error-base` не включает `valibot` в поставку. Если хост-проект не предоставляет `valibot@^1.0.0`, импорт не сможет разрешиться.
:::

## Импорт [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```

Также предусмотрен экспорт по умолчанию.

```ts
import I18nErrorBase from "i18n-error-base";
import setErrorMessage from "i18n-error-base";
```

:::note
Пакет распространяется как ESM (`"type": "module"`) без побочных эффектов (`"sideEffects": false`). Определения типов разрешаются из `dist/src/*.d.ts`.
:::
