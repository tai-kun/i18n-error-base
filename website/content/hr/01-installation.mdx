## Zahtjevi [#requirements]

- Izvršno okruženje koje može rukovati ES modulima, poput Node.js
- Kao peer ovisnost potreban je `valibot@^1.0.0`

`I18nErrorBase` interno referencira Valibot metodu `getGlobalConfig()` kako bi dohvatio trenutni `lang`. Čak i u projektima koji ne koriste Valibot, dovoljno je pozvati `setGlobalConfig({ lang })` samo radi prebacivanja jezika.

## Instalacija [#installation]

```package-install
npm i i18n-error-base
```

Ako Valibot još nije instaliran, dodajte ga zajedno.

```package-install
npm i valibot
```

:::warning[Pozor na peer ovisnost]
`i18n-error-base` ne uključuje `valibot`. Ako domaćin ne pripremi `valibot@^1.0.0`, doći će do pogreške razrješavanja pri uvozu.
:::

## Uvoz [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```

Dostupan je i zadani izvoz.

```ts
import I18nErrorBase from "i18n-error-base";
import setErrorMessage from "i18n-error-base";
```

:::note
Paket se distribuira kao ESM (`"type": "module"`) i nema nuspojava (`"sideEffects": false`). Definicije tipova razrješavaju se iz `dist/src/*.d.ts`.
:::
