## Zahtjevi [#requirements]

- Izvršno okruženje koje može rukovati ES modulima, poput Node.js
- Kao peer ovisnost potreban je `valibot@^1.0.0`

`message` slijedi `lang` iz Valibot metode `getGlobalConfig()`.

## Instalacija [#installation]

```package-install
npm i i18n-error-base
```

Ako Valibot još nije instaliran, dodajte ga zajedno.

```package-install
npm i valibot
```

:::warning[Pozor na peer ovisnost]
`valibot` nije uključen. Bez `valibot@^1.0.0` uvoz se ne može razriješiti.
:::

## Uvoz [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```
