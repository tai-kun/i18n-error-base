## Wymagania [#requirements]

- Środowisko wykonawcze obsługujące moduły ES, np. Node.js
- Jako zależność peer wymagany jest `valibot@^1.0.0`

`message` podąża za `lang` z `getGlobalConfig()` Valibotu.

## Instalacja [#installation]

```package-install
npm i i18n-error-base
```

Jeśli Valibot nie jest jeszcze zainstalowany, dodaj go również.

```package-install
npm i valibot
```

:::warning[Uwaga dotycząca zależności peer]
`valibot` nie jest dołączony. Bez `valibot@^1.0.0` import nie zostanie rozwiązany.
:::

## Import [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```
