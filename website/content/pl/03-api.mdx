## `I18nErrorBase` [#i18n-error-base]

Klasa bazowa do dziedziczenia po `Error`. Redefiniuje `message` jako getter i rozwiązuje go dynamicznie na podstawie `lang` z Valibot.

```ts
import { I18nErrorBase } from "i18n-error-base";

class MyError extends I18nErrorBase<{ code: string }> {}
```

### Parametry typu [#type-params]

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `TMeta` | `ErrorMeta \| undefined` | `ErrorMeta \| undefined` | Typ informacji dodatkowych przechowywanych jako `meta`. Podaj `undefined`, gdy ich nie używasz. |

### Właściwości statyczne [#static-props]

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `prefix?` | `string` | `undefined` | Gdy ustawione, jest dodawane na początku rozwiązanego komunikatu. |

### Właściwości instancji [#instance-props]

| Prop | Type | Description |
| ---- | ---- | ----------- |
| `meta` | `TMeta` | Informacje dodatkowe przekazane do konstruktora. Odczytywalne i zapisywalne. |
| `message` | `string` | Komunikat rozwiązany dla bieżącego `lang`. Wyliczalny. |
| `cause` | `unknown` | Przyczyna przekazana przez `ErrorOptions`. Standardowa właściwość `Error`. |

### Konstruktor [#constructor]

Gdy `TMeta` nie zawiera `undefined`, `meta` jest wymagane.

```ts
new MyError(meta, message, options?)
```

Gdy `TMeta` wynosi `undefined`, `meta` można pominąć.

```ts
new MyError(message, options?)
new MyError(meta, message, options?)
```

| Parametr | Typ | Opis |
| -------- | --- | ---- |
| `meta` | `TMeta` | Informacje dodatkowe używane do generowania komunikatów. |
| `message` | `string \| MessageFactory<TMeta>` | Komunikat domyślny używany dla języków bez rejestracji. Gdy jest funkcją, przyjmuje `meta`. |
| `options` | `ErrorOptions` | Opcje zgodne z drugim argumentem `Error` (np. `{ cause }`). |

Przekazanie wartości niebędącej ciągiem (np. liczby) jako `message` konwertuje ją na ciąg za pomocą `String(...)`. Gdy fabryka komunikatów zwróci pusty ciąg, `message` również jest pustym ciągiem.

### Kolejność rozwiązywania [#resolution-order]

1. Pobiera `lang` z `getGlobalConfig()` (gdy nie ustawiono, `"en"`)
2. Wykonuje funkcję zarejestrowaną przez `setErrorMessage` dla danej klasy i języka, z `meta`
3. Gdy brak rejestracji, używa komunikatu domyślnego z konstruktora (ciąg lub wynik obliczenia funkcji; po pierwszym obliczeniu przechowywany w pamięci podręcznej)
4. Jeśli istnieje `static prefix`, dodaje go na początku

:::note
Rejestracje są dopasowywane przez ścisłą równość `this.constructor`. Rejestracje w klasie nadrzędnej nie są dziedziczone przez klasy podrzędne. Zarejestruj każdą potrzebną klasę.
:::

## `setErrorMessage` [#set-error-message]

Rejestruje funkcję tworzącą komunikat dla języka.

```ts
import { setErrorMessage } from "i18n-error-base";

setErrorMessage(MyError, (meta) => `...: ${meta.code}`, "ja");
```

| Parametr | Typ | Opis |
| -------- | --- | ---- |
| `reference` | `I18nErrorBaseConstructor` | Klasa rozszerzająca `I18nErrorBase`. Klasy, które jej nie rozszerzają, powodują błąd typu. |
| `message` | `string \| (meta) => string` | Komunikat do zarejestrowania. Typ `meta` jest wywnioskowany z `meta` klasy docelowej. |
| `lang` | `string \| Iterable<string>` | Język docelowy. Pojedynczy kod lub iterowalny obiekt kodów (np. tablica). |

Ciągi są wewnętrznie konwertowane na funkcje przed zapisaniem. Ponowna rejestracja tej samej klasy i języka nadpisuje poprzedni wpis. Dane są przechowywane w `WeakMap` pod `globalThis.i18n_error_base__message_map`, z klasą jako kluczem i `Map` odwzorowującą języki na funkcje jako wartością.

## Typy [#types]

### `ErrorMeta` [#error-meta]

```ts
type ErrorMeta = {
  readonly [prop: string]: unknown;
};
```

Domyślne ograniczenie dla `TMeta`. Reprezentuje obiekt tylko do odczytu o dowolnych właściwościach.

### `ErrorOptions` [#error-options]

```ts
type ErrorOptions =
  ConstructorParameters<typeof Error> extends [
    message?: unknown,
    options?: (infer TOptions) | undefined,
  ]
    ? TOptions
    : { readonly cause?: unknown };
```

Typ wyprowadzony z drugiego argumentu konstruktora `Error` środowiska wykonawczego. Można przekazać opcje zawierające `cause`. Druga gałąź to fallback dla starszych środowisk.

### `MessageFactory<TMeta>` [#message-factory]

```ts
interface MessageFactory<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> {
  (meta: TMeta): string;
}
```

Funkcja generująca komunikat z `meta`. Używana zarówno dla komunikatu domyślnego konstruktora, jak i dla wartości zarejestrowanych przez `setErrorMessage`.

### `I18nErrorBaseParams<TMeta>` [#i18n-error-base-params]

Typ reprezentujący przeciążenia argumentów konstruktora.

```ts
type I18nErrorBaseParams<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> =
  [TMeta] extends [undefined]
    ?
        | [message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
        | [meta: undefined, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
    : [meta: TMeta, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined];
```

Forma bez `meta` jest dozwolona tylko wtedy, gdy `TMeta` wynosi `undefined`.

### `I18nErrorBaseConstructor` [#i18n-error-base-constructor]

```ts
interface I18nErrorBaseConstructor {
  new (...args: any): I18nErrorBase;
}
```

Typ pierwszego argumentu `setErrorMessage`. Wewnętrzny symbol identyfikujący zapobiega na poziomie typów przedostawaniu się klas, które nie rozszerzają `I18nErrorBase`.

## Uwagi [#notes]

- Domyślna wartość `lang` używana do rozwiązywania `message` to `"en"`. Przełącz ją jawnie za pomocą `setGlobalConfig({ lang })`
- Nie ma normalizacji kodów języków ani łańcucha fallback (np. wycofywania z `en-US` do `en`). Niezarejestrowane języki zawsze dają komunikat domyślny
- Dane rejestracji są przechowywane w procesowym `WeakMap`. Aby izolować testy, odrzuć je przez `globalThis.i18n_error_base__message_map = undefined`
