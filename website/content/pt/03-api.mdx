## `I18nErrorBase` [#i18n-error-base]

Classe base para herança de `Error`. Redefine `message` como um getter e resolve-a dinamicamente consoante o `lang` do Valibot.

```ts
import { I18nErrorBase } from "i18n-error-base";

class MyError extends I18nErrorBase<{ code: string }> {}
```

### Parâmetros de tipo [#type-params]

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `TMeta` | `ErrorMeta \| undefined` | `ErrorMeta \| undefined` | O tipo da informação auxiliar guardada como `meta`. Indique `undefined` quando não a utilizar. |

### Propriedades estáticas [#static-props]

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `prefix?` | `string` | `undefined` | Quando definido, é concatenado no início da mensagem resolvida. |

### Propriedades de instância [#instance-props]

| Prop | Type | Description |
| ---- | ---- | ----------- |
| `meta` | `TMeta` | A informação auxiliar passada ao construtor. Pode ser lida e escrita. |
| `message` | `string` | A mensagem resolvida para o `lang` atual. É enumerável. |
| `cause` | `unknown` | A causa passada em `ErrorOptions`. Propriedade-padrão de `Error`. |

### Construtor [#constructor]

Quando `TMeta` não inclui `undefined`, o `meta` é obrigatório.

```ts
new MyError(meta, message, options?)
```

Quando `TMeta` é `undefined`, o `meta` pode ser omitido.

```ts
new MyError(message, options?)
new MyError(meta, message, options?)
```

| Parâmetro | Tipo | Descrição |
| --------- | ---- | --------- |
| `meta` | `TMeta` | A informação auxiliar utilizada na geração de mensagens. |
| `message` | `string \| MessageFactory<TMeta>` | A mensagem por omissão utilizada para idiomas sem registo. Quando é uma função, recebe o `meta`. |
| `options` | `ErrorOptions` | Opções compatíveis com o segundo argumento de `Error` (como `{ cause }`). |

Se for passado a `message` um valor que não seja uma cadeia de caracteres (como um número), é convertido em cadeia com `String(...)`. Quando a fábrica de mensagens devolve uma cadeia vazia, `message` também é uma cadeia vazia.

### Ordem de resolução [#resolution-order]

1. Obtém o `lang` de `getGlobalConfig()` (quando não definido, `"en"`)
2. Executa, com o `meta`, a função dessa classe e desse idioma registada com `setErrorMessage`
3. Se não houver registo, utiliza a mensagem por omissão do construtor (uma cadeia de caracteres ou o resultado avaliado de uma função; após a primeira avaliação, guardada em cache)
4. Se existir `static prefix`, concatena-o no início

:::note
A correspondência do registo é por igualdade estrita de `this.constructor`. O registo na classe progenitora não é herdado pelas classes descendentes. Registe para cada classe necessária.
:::

## `setErrorMessage` [#set-error-message]

Regista a função de criação de mensagens de cada idioma.

```ts
import { setErrorMessage } from "i18n-error-base";

setErrorMessage(MyError, (meta) => `...: ${meta.code}`, "ja");
```

| Parâmetro | Tipo | Descrição |
| --------- | ---- | --------- |
| `reference` | `I18nErrorBaseConstructor` | Uma classe que herda de `I18nErrorBase`. Classes que não herdam dão erro de tipo. |
| `message` | `string \| (meta) => string` | A mensagem a registar. O tipo de `meta` é inferido a partir do `meta` da classe visada. |
| `lang` | `string \| Iterable<string>` | O idioma visado. Um único código ou um objeto iterável de códigos (como um vetor). |

As cadeias de caracteres são convertidas internamente em funções para serem guardadas. Voltar a registar a mesma classe e o mesmo idioma substitui o registo. O destino de armazenamento é o `WeakMap` em `globalThis.i18n_error_base__message_map`, cuja chave é a classe e cujo valor é um `Map` do idioma para a função.

## Tipos [#types]

### `ErrorMeta` [#error-meta]

```ts
type ErrorMeta = {
  readonly [prop: string]: unknown;
};
```

É a restrição por omissão de `TMeta`. Representa um objeto só de leitura com propriedades arbitrárias.

### `ErrorOptions` [#error-options]

```ts
type ErrorOptions =
  ConstructorParameters<typeof Error> extends [
    message?: unknown,
    options?: (infer TOptions) | undefined,
  ]
    ? TOptions
    : { readonly cause?: unknown };
```

Tipo derivado do segundo argumento do construtor de `Error` do ambiente de execução. Permite passar opções com `cause`. O segundo ramo é um recurso para ambientes antigos.

### `MessageFactory<TMeta>` [#message-factory]

```ts
interface MessageFactory<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> {
  (meta: TMeta): string;
}
```

Função que gera uma mensagem a partir de `meta`. Pode ser utilizada tanto na mensagem por omissão do construtor como no valor de registo de `setErrorMessage`.

### `I18nErrorBaseParams<TMeta>` [#i18n-error-base-params]

Tipo que representa as sobrecargas de argumentos do construtor.

```ts
type I18nErrorBaseParams<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> =
  [TMeta] extends [undefined]
    ?
        | [message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
        | [meta: undefined, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
    : [meta: TMeta, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined];
```

A forma abreviada com omissão de `meta` só é permitida quando `TMeta` é `undefined`.

### `I18nErrorBaseConstructor` [#i18n-error-base-constructor]

```ts
interface I18nErrorBaseConstructor {
  new (...args: any): I18nErrorBase;
}
```

O tipo do primeiro argumento de `setErrorMessage`. Através de um símbolo de identificação interna, impede ao nível de tipos a mistura de classes que não herdam de `I18nErrorBase`.

## Notas [#notes]

- O valor por omissão de `lang` utilizado na resolução de `message` é `"en"`. Mude-o explicitamente com `setGlobalConfig({ lang })`
- Não há normalização de códigos de idioma nem cadeia de recurso (ex.: recuo de `en-US` para `en`). Idiomas sem registo recorrem uniformemente à mensagem por omissão
- Os dados registados são mantidos no `WeakMap` global do processo. Para os isolar em testes, podem ser eliminados com `globalThis.i18n_error_base__message_map = undefined`
