เป็นคลาสพื้นฐานสำหรับการสืบทอด `Error` ที่สลับ `message` แบบไดนามิกตามการตั้งค่าภาษาโกลบอล (`lang`) ของ Valibot

```ts
import { setGlobalConfig } from "valibot";
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";

class NotFoundError extends I18nErrorBase<{ resource: string }> {}

setErrorMessage(NotFoundError, ({ resource }) => `リソースが見つかりません: ${resource}`, "ja");
setErrorMessage(NotFoundError, ({ resource }) => `Resource not found: ${resource}`, "en");

const error = new NotFoundError({ resource: "user" }, "fallback message");

setGlobalConfig({ lang: "ja" });
console.log(error.message); // リソースが見つかりません: user

setGlobalConfig({ lang: "en" });
console.log(error.message); // Resource not found: user
```

เนื่องจากจะอ้างอิง `lang` ณ ขณะนั้นทุกครั้งที่มีการเข้าถึง `message` จึงสามารถสลับภาษาได้โดยไม่ต้องสร้างอินสแตนซ์ใหม่ สำหรับภาษาที่ยังไม่ได้ลงทะเบียน จะ fallback ไปใช้ข้อความเริ่มต้นที่ส่งให้คอนสตรักเตอร์

## คุณสมบัติ [#features]

- เชื่อมต่อกับ `getGlobalConfig()` / `setGlobalConfig({ lang })` ของ Valibot และ resolve `message` แบบไดนามิก
- ลงทะเบียนข้อความแยกตามภาษาภายหลังด้วย `setErrorMessage` สามารถลงทะเบียนฟังก์ชันที่รับ `meta` ได้
- สำหรับภาษาที่ยังไม่ได้ลงทะเบียน จะ fallback ไปใช้ข้อความเริ่มต้นของคอนสตรักเตอร์
- สามารถใส่คำนำหน้าข้อความด้วย `static prefix` ระดับคลาส
- เก็บ `meta` ไว้ในคอนสตรักเตอร์และส่งต่อให้ฟังก์ชันสร้างข้อความ
- เนื่องจากสืบทอดจาก `Error` จึงใช้ `instanceof Error`, `cause`, `stack` ได้ตามปกติ
- ที่เก็บข้อความเป็น `WeakMap` จึงทำ garbage collect คลาสที่ไม่ใช้แล้วได้

## หลักการทำงาน [#how-it-works]

คอนสตรักเตอร์ของ `I18nErrorBase` กำหนด `message` เป็น getter โดยจะ resolve ตามลำดับต่อไปนี้ทุกครั้งที่มีการเข้าถึง

1. ดึง `lang` จาก `getGlobalConfig()` หากยังไม่ได้ตั้งค่าจะเป็น `"en"`
2. หากมีฟังก์ชัน `(คลาส × lang)` ที่ลงทะเบียนด้วย `setErrorMessage` จะเรียกใช้โดยส่ง `meta` ไป
3. หากไม่มี จะคืนข้อความเริ่มต้นที่ส่งให้คอนสตรักเตอร์ (สตริงหรือผลลัพธ์ของฟังก์ชัน)
4. หากตั้งค่า `static prefix` ไว้ จะเชื่อมต่อไว้ที่ด้านหน้า

:::tip
ข้อความเริ่มต้นในรูปแบบฟังก์ชันจะถูกประเมินเมื่อเข้าถึงครั้งแรกและถูกแคชไว้หลังจากนั้น ข้อความของภาษาที่ลงทะเบียนไว้จะถูกสร้างใหม่จาก `meta` ทุกครั้งที่มีการเข้าถึง ดังนั้นการสลับภาษาจึงมีผลทันที
:::
