## `I18nErrorBase` [#i18n-error-base]

เป็นคลาสพื้นฐานสำหรับการสืบทอด `Error` โดยนิยาม `message` ใหม่เป็น getter และ resolve แบบไดนามิกตาม `lang` ของ Valibot

```ts
import { I18nErrorBase } from "i18n-error-base";

class MyError extends I18nErrorBase<{ code: string }> {}
```

### พารามิเตอร์ชนิด [#type-params]

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `TMeta` | `ErrorMeta \| undefined` | `ErrorMeta \| undefined` | ชนิดของข้อมูลประกอบที่เก็บเป็น `meta` หากไม่ใช้ให้ระบุ `undefined` |

### คุณสมบัติสแตติก [#static-props]

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `prefix?` | `string` | `undefined` | หากตั้งค่าจะเชื่อมต่อไว้ที่ด้านหน้าของข้อความที่ resolve แล้ว |

### คุณสมบัติอินสแตนซ์ [#instance-props]

| Prop | Type | Description |
| ---- | ---- | ----------- |
| `meta` | `TMeta` | ข้อมูลประกอบที่ส่งให้คอนสตรักเตอร์ สามารถอ่านและเขียนได้ |
| `message` | `string` | ข้อความที่ resolve ตาม `lang` ปัจจุบัน สามารถ enumerate ได้ |
| `cause` | `unknown` | สาเหตุที่ส่งผ่าน `ErrorOptions` เป็นคุณสมบัติมาตรฐานของ `Error` |

### คอนสตรักเตอร์ [#constructor]

หาก `TMeta` ไม่รวม `undefined` `meta` จะเป็นค่าบังคับ

```ts
new MyError(meta, message, options?)
```

หาก `TMeta` เป็น `undefined` สามารถละ `meta` ได้

```ts
new MyError(message, options?)
new MyError(meta, message, options?)
```

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| ------------ | -- | ---- |
| `meta` | `TMeta` | ข้อมูลประกอบที่ใช้สร้างข้อความ |
| `message` | `string \| MessageFactory<TMeta>` | ข้อความเริ่มต้นที่ใช้สำหรับภาษาที่ยังไม่ได้ลงทะเบียน หากเป็นฟังก์ชันจะรับ `meta` |
| `options` | `ErrorOptions` | ออปชันที่เข้ากันได้กับอาร์กิวเมนต์ตัวที่ 2 ของ `Error` (เช่น `{ cause }`) |

หากส่งค่าที่ไม่ใช่สตริง (เช่นตัวเลข) ให้ `message` จะถูกแปลงเป็นสตริงด้วย `String(...)` หาก message factory คืนสตริงว่าง `message` ก็จะเป็นสตริงว่างเช่นกัน

### ลำดับการ resolve [#resolution-order]

1. ดึง `lang` ของ `getGlobalConfig()` (หากยังไม่ได้ตั้งค่าจะเป็น `"en"`)
2. เรียกใช้ฟังก์ชันของคลาสและภาษานั้นที่ลงทะเบียนด้วย `setErrorMessage` พร้อม `meta`
3. หากยังไม่ได้ลงทะเบียน จะใช้ข้อความเริ่มต้นของคอนสตรักเตอร์ (สตริงหรือผลการประเมินฟังก์ชัน แคชหลังประเมินครั้งแรก)
4. หากมี `static prefix` จะเชื่อมต่อไว้ที่ด้านหน้า

:::note
การจับคู่การลงทะเบียนใช้การตรงกันทั้งหมดของ `this.constructor` การลงทะเบียนในคลาสแม่จะไม่ถูกสืบทอดไปยังคลาสลูก โปรดลงทะเบียนแยกสำหรับแต่ละคลาสที่ต้องการ
:::

## `setErrorMessage` [#set-error-message]

ลงทะเบียนฟังก์ชันสร้างข้อความแยกตามภาษา

```ts
import { setErrorMessage } from "i18n-error-base";

setErrorMessage(MyError, (meta) => `...: ${meta.code}`, "ja");
```

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| ------------ | -- | ---- |
| `reference` | `I18nErrorBaseConstructor` | คลาสที่สืบทอด `I18nErrorBase` หากเป็นคลาสที่ไม่ได้สืบทอดจะเกิด type error |
| `message` | `string \| (meta) => string` | ข้อความที่จะลงทะเบียน ชนิดของ `meta` จะถูกอนุมานจาก `meta` ของคลาสเป้าหมาย |
| `lang` | `string \| Iterable<string>` | ภาษาเป้าหมาย รหัสเดียวหรืออ็อบเจกต์ที่ทำซ้ำได้ของรหัส (เช่นอาร์เรย์) |

สตริงจะถูกแปลงเป็นฟังก์ชันภายในก่อนเก็บไว้ การลงทะเบียนซ้ำในคลาสและภาษาเดิมจะเขียนทับ ที่เก็บคือ `WeakMap` ของ `globalThis.i18n_error_base__message_map` โดยคีย์คือคลาสและค่าคือ `Map` จากภาษาไปยังฟังก์ชัน

## ชนิด [#types]

### `ErrorMeta` [#error-meta]

```ts
type ErrorMeta = {
  readonly [prop: string]: unknown;
};
```

เป็นข้อจำกัดเริ่มต้นของ `TMeta` แสดงถึงอ็อบเจกต์แบบอ่านอย่างเดียวที่มีคุณสมบัติตามต้องการ

### `ErrorOptions` [#error-options]

```ts
type ErrorOptions =
  ConstructorParameters<typeof Error> extends [
    message?: unknown,
    options?: (infer TOptions) | undefined,
  ]
    ? TOptions
    : { readonly cause?: unknown };
```

เป็นชนิดที่ได้จากอาร์กิวเมนต์ตัวที่ 2 ของคอนสตรักเตอร์ `Error` ในสภาพแวดล้อมรันไทม์ สามารถส่งออปชันที่มี `cause` ได้ สาขาหลังคือ fallback สำหรับสภาพแวดล้อมเก่า

### `MessageFactory<TMeta>` [#message-factory]

```ts
interface MessageFactory<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> {
  (meta: TMeta): string;
}
```

เป็นฟังก์ชันที่สร้างข้อความจาก `meta` ใช้ได้ทั้งข้อความเริ่มต้นของคอนสตรักเตอร์และค่าที่ลงทะเบียนของ `setErrorMessage`

### `I18nErrorBaseParams<TMeta>` [#i18n-error-base-params]

เป็นชนิดที่แสดง overload ของอาร์กิวเมนต์คอนสตรักเตอร์

```ts
type I18nErrorBaseParams<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> =
  [TMeta] extends [undefined]
    ?
        | [message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
        | [meta: undefined, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
    : [meta: TMeta, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined];
```

เฉพาะเมื่อ `TMeta` เป็น `undefined` เท่านั้นจึงอนุญาตรูปแบบละ `meta`

### `I18nErrorBaseConstructor` [#i18n-error-base-constructor]

```ts
interface I18nErrorBaseConstructor {
  new (...args: any): I18nErrorBase;
}
```

เป็นชนิดของอาร์กิวเมนต์ตัวที่ 1 ของ `setErrorMessage` ป้องกันการปะปนของคลาสที่ไม่ได้สืบทอด `I18nErrorBase` ในระดับชนิดด้วยสัญลักษณ์ระบุตัวตนภายใน

## หมายเหตุเพิ่มเติม [#notes]

- ค่าเริ่มต้นของ `lang` ที่ใช้ resolve `message` คือ `"en"` โปรดสลับอย่างชัดเจนด้วย `setGlobalConfig({ lang })`
- ไม่มีการ normalize รหัสภาษาหรือ fallback chain (เช่นถอยจาก `en-US` ไป `en`) ภาษาที่ยังไม่ได้ลงทะเบียนทั้งหมดจะเป็นข้อความเริ่มต้นเหมือนกัน
- ข้อมูลที่ลงทะเบียนจะเก็บใน `WeakMap` ของทั้งโปรเซส หากต้องการแยกในเทสต์ สามารถทิ้งได้ด้วย `globalThis.i18n_error_base__message_map = undefined`
