## ข้อกำหนด [#requirements]

- สภาพแวดล้อมรันไทม์ที่รองรับ ES โมดูล เช่น Node.js
- ต้องมี `valibot@^1.0.0` เป็น peer dependency

`I18nErrorBase` อ้างอิง `getGlobalConfig()` ของ Valibot ภายในเพื่อดึง `lang` ปัจจุบัน แม้ในโปรเจกต์ที่ไม่ได้ใช้ Valibot ก็สามารถทำงานได้เพียงเรียก `setGlobalConfig({ lang })` เพื่อสลับภาษา

## การติดตั้ง [#installation]

```package-install
npm i i18n-error-base
```

หากยังไม่ได้ติดตั้ง Valibot โปรดเพิ่มด้วย

```package-install
npm i valibot
```

:::warning[ข้อควรระวังเกี่ยวกับ peer dependency]
`i18n-error-base` ไม่ได้ bundle `valibot` มาให้ หากโฮสต์ไม่ได้เตรียม `valibot@^1.0.0` ไว้ การ import จะเกิดข้อผิดพลาดในการ resolve
:::

## การ import [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```

มี default export ให้ใช้งานด้วย

```ts
import I18nErrorBase from "i18n-error-base";
import setErrorMessage from "i18n-error-base";
```

:::note
แพ็กเกจเผยแพร่เป็น ESM (`"type": "module"`) และไม่มี side effect (`"sideEffects": false`) นิยามชนิดจะถูก resolve จาก `dist/src/*.d.ts`
:::
