## ข้อกำหนด [#requirements]

- สภาพแวดล้อมรันไทม์ที่รองรับ ES โมดูล เช่น Node.js
- ต้องมี `valibot@^1.0.0` เป็น peer dependency

`message` จะตาม `lang` จาก `getGlobalConfig()` ของ Valibot

## การติดตั้ง [#installation]

```package-install
npm i i18n-error-base
```

หากยังไม่ได้ติดตั้ง Valibot โปรดเพิ่มด้วย

```package-install
npm i valibot
```

:::warning[ข้อควรระวังเกี่ยวกับ peer dependency]
`valibot` ไม่ได้ถูก bundle มาด้วย หากไม่มี `valibot@^1.0.0` การ import จะล้มเหลว
:::

## การ import [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```
