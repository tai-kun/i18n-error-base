## `I18nErrorBase` [#i18n-error-base]

`Error` sınıfını genişletmek için kullanılan temel sınıftır. `message` değerini alıcı (getter) olarak yeniden tanımlar ve Valibot'un `lang` değerine göre dinamik olarak çözer.

```ts
import { I18nErrorBase } from "i18n-error-base";

class MyError extends I18nErrorBase<{ code: string }> {}
```

### Tür parametreleri [#type-params]

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `TMeta` | `ErrorMeta \| undefined` | `ErrorMeta \| undefined` | `meta` olarak saklanan ek bilginin türü. Kullanılmıyorsa `undefined` belirtin. |

### Statik özellikler [#static-props]

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `prefix?` | `string` | `undefined` | Ayarlanırsa çözümlenmiş mesajın başına eklenir. |

### Örnek özellikleri [#instance-props]

| Prop | Type | Description |
| ---- | ---- | ----------- |
| `meta` | `TMeta` | Oluşturucuya geçirilen ek bilgi. Okunabilir ve yazılabilir. |
| `message` | `string` | Geçerli `lang` değerine göre çözümlenen mesaj. Numaralandırılabilir. |
| `cause` | `unknown` | `ErrorOptions` ile geçirilen neden. `Error` standart özelliğidir. |

### Oluşturucu [#constructor]

`TMeta` değeri `undefined` içermiyorsa, `meta` zorunludur.

```ts
new MyError(meta, message, options?)
```

`TMeta` değeri `undefined` ise, `meta` atlanabilir.

```ts
new MyError(message, options?)
new MyError(meta, message, options?)
```

| Parametre | Tür | Açıklama |
| --------- | --- | -------- |
| `meta` | `TMeta` | Mesaj üretiminde kullanılan ek bilgi. |
| `message` | `string \| MessageFactory<TMeta>` | Kayıtlı mesajı olmayan dillerde kullanılan varsayılan mesaj. İşlev ise `meta` alır. |
| `options` | `ErrorOptions` | `Error` 2. bağımsız değişkeniyle uyumlu seçenekler (`{ cause }` gibi). |

`message` olarak dizge dışı bir değer (sayı gibi) geçirilirse `String(...)` ile dizgeye dönüştürülür. Mesaj üretim işlevi boş dizge döndürürse `message` de boş dizge olur.

### Çözümleme sırası [#resolution-order]

1. `getGlobalConfig()` işlevinden `lang` alınır (ayarlanmamışsa `"en"`)
2. `setErrorMessage` ile kaydedilmiş ilgili sınıfa ve dile ait işlev `meta` ile çalıştırılır
3. Kayıt yoksa oluşturucunun varsayılan mesajı kullanılır (dizge veya işlevin değerlendirme sonucu. İlk değerlendirmeden sonra önbelleğe alınır)
4. `static prefix` varsa başa eklenir

:::note
Kayıt eşleştirmesi `this.constructor` tam eşitliğidir. Üst sınıfa yapılan kayıtlar alt sınıflara aktarılmaz. Gerekli her sınıf için ayrı ayrı kaydedin.
:::

## `setErrorMessage` [#set-error-message]

Dile özgü mesaj üretim işlevini kaydeder.

```ts
import { setErrorMessage } from "i18n-error-base";

setErrorMessage(MyError, (meta) => `...: ${meta.code}`, "ja");
```

| Parametre | Tür | Açıklama |
| --------- | --- | -------- |
| `reference` | `I18nErrorBaseConstructor` | `I18nErrorBase` sınıfından türetilmiş sınıf. Türetmemiş sınıflar tür hatası olur. |
| `message` | `string \| (meta) => string` | Kaydedilecek mesaj. `meta` türü hedef sınıfın `meta` değerinden çıkarılır. |
| `lang` | `string \| Iterable<string>` | Hedef dil. Tek kod veya kodların yinelenebilir nesnesi (dizi gibi). |

Dizgeler dahili olarak işleve dönüştürülerek saklanır. Aynı sınıfa ve dile yeniden kayıt üzerine yazar. Saklama yeri `globalThis.i18n_error_base__message_map` üzerindeki `WeakMap` olup, anahtar sınıftır ve değer dilden işleve giden bir `Map` olur.

## Türler [#types]

### `ErrorMeta` [#error-meta]

```ts
type ErrorMeta = {
  readonly [prop: string]: unknown;
};
```

`TMeta` varsayılan kısıtıdır. Rastgele özelliklere sahip salt okunur nesneyi temsil eder.

### `ErrorOptions` [#error-options]

```ts
type ErrorOptions =
  ConstructorParameters<typeof Error> extends [
    message?: unknown,
    options?: (infer TOptions) | undefined,
  ]
    ? TOptions
    : { readonly cause?: unknown };
```

Çalıştırma ortamının `Error` oluşturucu 2. bağımsız değişkeninden türetilmiş türdür. `cause` içeren seçenekler geçirilebilir. İkinci dal eski ortamlara yönelik geri dönüş içindir.

### `MessageFactory<TMeta>` [#message-factory]

```ts
interface MessageFactory<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> {
  (meta: TMeta): string;
}
```

`meta` değerinden mesaj üreten işlevdir. Oluşturucunun varsayılan mesajında da `setErrorMessage` kayıt değerinde de kullanılabilir.

### `I18nErrorBaseParams<TMeta>` [#i18n-error-base-params]

Oluşturucu bağımsız değişkeni aşırı yüklemelerini temsil eden türdür.

```ts
type I18nErrorBaseParams<TMeta extends ErrorMeta | undefined = ErrorMeta | undefined> =
  [TMeta] extends [undefined]
    ?
        | [message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
        | [meta: undefined, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined]
    : [meta: TMeta, message: string | MessageFactory<TMeta>, options?: ErrorOptions | undefined];
```

`meta` içermeyen biçim yalnızca `TMeta` değeri `undefined` olduğunda izin verilir.

### `I18nErrorBaseConstructor` [#i18n-error-base-constructor]

```ts
interface I18nErrorBaseConstructor {
  new (...args: any): I18nErrorBase;
}
```

`setErrorMessage` 1. bağımsız değişkeninin türüdür. Dahili tanımlama simgesi sayesinde, `I18nErrorBase` sınıfından türememiş sınıfların karışması tür düzeyinde engellenir.

## Notlar [#notes]

- `message` çözümlemesinde kullanılan `lang` varsayılan değeri `"en"` olur. `setGlobalConfig({ lang })` ile açıkça değiştirin
- Dil kodu normalleştirme veya geri dönüş zinciri (ör: `en-US` değerinden `en` değerine dönüş) yoktur. Kayıtsız diller her zaman varsayılan mesaj olur
- Kayıt verileri süreç genelindeki `WeakMap` içinde saklanır. Testlerde yalıtmak isterseniz `globalThis.i18n_error_base__message_map = undefined` ile yok edebilirsiniz
