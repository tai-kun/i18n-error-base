En basisklasse til nedarvning af `Error`, der dynamisk skifter `message` i takt med Valibots globale sprogindstilling (`lang`).

```ts
import { setGlobalConfig } from "valibot";
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";

class NotFoundError extends I18nErrorBase<{ resource: string }> {}

setErrorMessage(NotFoundError, ({ resource }) => `リソースが見つかりません: ${resource}`, "ja");
setErrorMessage(NotFoundError, ({ resource }) => `Resource not found: ${resource}`, "en");

const error = new NotFoundError({ resource: "user" }, "fallback message");

setGlobalConfig({ lang: "ja" });
console.log(error.message); // リソースが見つかりません: user

setGlobalConfig({ lang: "en" });
console.log(error.message); // Resource not found: user
```

Da den aktuelle `lang` slås op, hver gang der tilgås `message`, kan du skifte sprog uden at genskabe instanser. For sprog uden registrering falder den tilbage til standardmeddelelsen fra konstruktøren.

## Funktioner [#features]

- Løser `message` dynamisk i takt med Valibots `getGlobalConfig()` / `setGlobalConfig({ lang })`
- Registrer sprogspecifikke meddelelser efterfølgende med `setErrorMessage`. Du kan også registrere funktioner, der modtager `meta`
- Falder tilbage til konstruktørens standardmeddelelse for sprog uden registrering
- Kan tilføje et præfiks foran meddelelsen via klassens `static prefix`
- Beholder `meta` fra konstruktøren og sender den til meddelelsesfunktioner
- Nedarver fra `Error`, så `instanceof Error`, `cause` og `stack` virker som normalt
- Gemmer meddelelser i et `WeakMap`, så ubrugte klasser kan garbage collectes

## Sådan fungerer det [#how-it-works]

`I18nErrorBase`-konstruktøren definerer `message` som en getter. Den løses i følgende rækkefølge ved hver adgang.

1. Henter `lang` fra `getGlobalConfig()`. Den er `"en"`, når den ikke er angivet
2. Hvis der findes en `(klasse × lang)`-funktion registreret med `setErrorMessage`, udføres den med `meta`
3. Ellers returneres standardmeddelelsen fra konstruktøren (en streng eller resultatet af en funktion)
4. Hvis `static prefix` er angivet, sættes det foran

:::tip
Funktionsformen af standardmeddelelsen evalueres ved første adgang og caches derefter. Meddelelser for registrerede sprog genskabes fra `meta` ved hver adgang, så sprogskift slår igennem med det samme.
:::
