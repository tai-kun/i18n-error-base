## Krav [#requirements]

- Et kørselsmiljø, der kan håndtere ES-moduler, f.eks. Node.js
- `valibot@^1.0.0` kræves som peer-afhængighed

`message` følger `lang` fra Valibots `getGlobalConfig()`.

## Installation [#installation]

```package-install
npm i i18n-error-base
```

Hvis Valibot ikke er installeret endnu, skal du også tilføje det.

```package-install
npm i valibot
```

:::warning[Advarsel om peer-afhængighed]
`valibot` medtages ikke. Uden `valibot@^1.0.0` kan importen ikke løses.
:::

## Import [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```
