## Requisitos [#requirements]

- Um ambiente de execução onde você consiga usar módulos ES, como Node.js
- `valibot@^1.0.0` como dependência peer

`I18nErrorBase` consulta internamente o `getGlobalConfig()` do Valibot para pegar o `lang` atual. Mesmo em um projeto onde você não usa Valibot, basta chamar `setGlobalConfig({ lang })` só para trocar o idioma que já funciona.

## Instalação [#installation]

```package-install
npm i i18n-error-base
```

Se você ainda não instalou o Valibot, adicione junto.

```package-install
npm i valibot
```

:::warning[Atenção com a dependência peer]
`i18n-error-base` não inclui o `valibot`. Se você não tiver `valibot@^1.0.0` no seu projeto, vai dar erro de resolução na hora de importar.
:::

## Importação [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```

Também há uma exportação padrão para você usar.

```ts
import I18nErrorBase from "i18n-error-base";
import setErrorMessage from "i18n-error-base";
```

:::note
O pacote é distribuído como ESM (`"type": "module"`) e não tem efeitos colaterais (`"sideEffects": false`). As definições de tipos são resolvidas a partir de `dist/src/*.d.ts`.
:::
