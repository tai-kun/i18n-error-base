## Requisitos [#requirements]

- Um ambiente de execução onde você consiga usar módulos ES, como Node.js.
- `valibot@^1.0.0` como dependência peer.

`message` segue o `lang` do `getGlobalConfig()` do Valibot.

## Instalação [#installation]

```package-install
npm i i18n-error-base
```

Se você ainda não instalou o Valibot, adicione junto.

```package-install
npm i valibot
```

:::warning[Atenção com a dependência peer]
`valibot` não vem junto. Sem `valibot@^1.0.0`, a importação dá erro de resolução.
:::

## Importação [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```
