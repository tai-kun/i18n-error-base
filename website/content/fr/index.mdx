Classe de base pour hériter de `Error`, qui bascule dynamiquement `message` en fonction du paramètre linguistique global (`lang`) de Valibot.

```ts
import { setGlobalConfig } from "valibot";
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";

class NotFoundError extends I18nErrorBase<{ resource: string }> {}

setErrorMessage(NotFoundError, ({ resource }) => `リソースが見つかりません: ${resource}`, "ja");
setErrorMessage(NotFoundError, ({ resource }) => `Resource not found: ${resource}`, "en");

const error = new NotFoundError({ resource: "user" }, "fallback message");

setGlobalConfig({ lang: "ja" });
console.log(error.message); // リソースが見つかりません: user

setGlobalConfig({ lang: "en" });
console.log(error.message); // Resource not found: user
```

Comme `lang` est consulté au moment de chaque accès à `message`, vous pouvez changer de langue sans recréer d'instance. Pour les langues sans enregistrement, le message par défaut passé au constructeur est utilisé en repli.

## Fonctionnalités [#features]

- Résout dynamiquement `message` en lien avec `getGlobalConfig()` / `setGlobalConfig({ lang })` de Valibot
- Les messages par langue s'enregistrent ultérieurement avec `setErrorMessage`. Des fonctions recevant `meta` peuvent aussi être enregistrées
- Pour les langues sans enregistrement, le message par défaut du constructeur est utilisé en repli
- Un `static prefix` par classe permet d'ajouter un préfixe au début du message
- Conserve `meta` dans le constructeur et le transmet aux fonctions de génération de messages
- Comme elle hérite de `Error`, `instanceof Error`, `cause` et `stack` s'utilisent tels quels
- Les messages sont stockés dans une `WeakMap`, de sorte que les classes devenues inutiles sont ramassées par le ramasse-miettes

## Fonctionnement [#how-it-works]

Le constructeur de `I18nErrorBase` définit `message` comme un accesseur. Il est résolu à chaque accès dans l'ordre suivant.

1. Obtient `lang` depuis `getGlobalConfig()`. Vaut `"en"` si non défini
2. S'il existe une fonction `(classe × lang)` enregistrée avec `setErrorMessage`, l'exécute en lui passant `meta`
3. Sinon, retourne le message par défaut passé au constructeur (une chaîne ou le résultat d'une fonction)
4. Si `static prefix` est défini, le concatène au début

:::tip
La forme fonctionnelle du message par défaut est évaluée au premier accès, puis mise en cache. Les messages des langues enregistrées sont régénérés depuis `meta` à chaque accès, de sorte que le changement de langue est reflété immédiatement.
:::
