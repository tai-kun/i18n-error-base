## Prérequis [#requirements]

- Environnement d'exécution capable de gérer les modules ES, comme Node.js
- `valibot@^1.0.0` est requis comme dépendance peer

`I18nErrorBase` se réfère en interne à `getGlobalConfig()` de Valibot pour obtenir le `lang` actuel. Même dans un projet qui n'utilise pas Valibot, il suffit d'appeler `setGlobalConfig({ lang })` pour le changement de langue.

## Installation [#installation]

```package-install
npm i i18n-error-base
```

Si Valibot n'est pas encore installé, ajoutez-le également.

```package-install
npm i valibot
```

:::warning[Dépendance peer à noter]
`i18n-error-base` ne bundle pas `valibot`. Sans `valibot@^1.0.0` côté hôte, l'importation provoquera une erreur de résolution.
:::

## Import [#import]

```ts
import { I18nErrorBase, setErrorMessage } from "i18n-error-base";
import type { ErrorMeta, ErrorOptions, I18nErrorBaseParams, MessageFactory } from "i18n-error-base";
```

Une exportation par défaut est également fournie.

```ts
import I18nErrorBase from "i18n-error-base";
import setErrorMessage from "i18n-error-base";
```

:::note
Le paquet est distribué en ESM (`"type": "module"`) et sans effets de bord (`"sideEffects": false`). Les définitions de types sont résolues depuis `dist/src/*.d.ts`.
:::
