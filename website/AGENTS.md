## 開発

開発サーバーを起動するときは、バックグラウンドモードを使用してください。

```sh
astro dev --background
```

バックグラウンドで実行中のサーバーは、`astro dev stop`、`astro dev status`、`astro dev logs` で停止・状態確認・ログの表示ができます。
